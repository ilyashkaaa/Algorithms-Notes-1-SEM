[Определение] Бинарная пирамида и поддержка инварианта

Бинарная пирамида (куча): Массив $A[0 \dots n-1]$, интерпретируемый как почти полное бинарное дерево, где для узла с индексом $i$:

$$\mathrm{parent}(i) = \left\lfloor \frac{i-1}{2} \right\rfloor, \quad \mathrm{left}(i) = 2i + 1, \quad \mathrm{right}(i) = 2i + 2$$

Для реализации пирамидальной сортировки используется Max-Heap (куча на максимум): для любого узла $i > 0$ выполняется $A[i] \le A[\mathrm{parent}(i)]$. Максимальный элемент всего массива находится в корне $A[0]$.

Процедура $\mathrm{siftDown}(i, n)$: Если элемент $A[i]$ меньше кого-то из своих сыновей, меняем его с наибольшим из сыновей и рекурсивно опускаем вниз. Время работы пропорционально высоте узла: $O(h)$.

[Алгоритм] Построение кучи снизу вверх за $O(n)$ (Heapify)

Задача: Превратить произвольный неупорядоченный массив $A[0 \dots n-1]$ в корректную Max-Heap на месте.

Идея построения кучи снизу вверх (Bottom-Up Heapify):

  • Листья дерева (узлы с индексами от $\lfloor n/2 \rfloor$ до $n-1$) не имеют сыновей и уже тривиально образуют корректные одноэлементные кучи.
  • Будем подниматься от последнего нелистового узла $i = \lfloor n/2 \rfloor - 1$ к корню $i = 0$ и вызывать $\mathrm{siftDown}(i)$.
  • Инвариант: Перед вызовом $\mathrm{siftDown}(i)$ оба поддерева $\mathrm{left}(i)$ и $\mathrm{right}(i)$ уже являются корректными кучами. После просеивания поддерево с корнем в $i$ становится корректной кучей.
[Теорема и Доказательство] Линейная сложность построения $O(n)$

Теорема: Построение бинарной кучи методом $\mathrm{Heapify}$ из произвольного массива размера $n$ выполняется за время $O(n)$.

Доказательство: Высота узла $h$ — это длина максимального пути от узла до листа в его поддереве.

  1. В куче из $n$ элементов число узлов на высоте $h$ не превосходит $\left\lceil \frac{n}{2^{h+1}} \right\rceil$.
  2. Время просеивания узла на высоте $h$ пропорционально $O(h)$ шагов.
  3. Суммарное число операций: $$T(n) \le \sum_{h=0}^{\lfloor \log_2 n \rfloor} \left\lceil \frac{n}{2^{h+1}} \right\rceil O(h) = O\left(n \sum_{h=1}^\infty \frac{h}{2^h}\right)$$
  4. Вычисление суммы бесконечного ряда $S = \sum_{h=1}^\infty \frac{h}{2^h}$ методом сдвига: $$S = \frac{1}{2} + \frac{2}{4} + \frac{3}{8} + \frac{4}{16} + \frac{5}{32} + \dots$$ Умножим ряд на $\frac{1}{2}$: $$\frac{1}{2}S = \frac{1}{4} + \frac{2}{8} + \frac{3}{16} + \frac{4}{32} + \dots$$ Вычтем второе равенство из первого: $$S - \frac{1}{2}S = \frac{1}{2} + \left(\frac{2}{4} - \frac{1}{4}\right) + \left(\frac{3}{8} - \frac{2}{8}\right) + \left(\frac{4}{16} - \frac{3}{16}\right) + \dots$$ $$\frac{1}{2}S = \frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{1}{16} + \dots = \frac{1/2}{1 - 1/2} = 1 \implies S = 2$$

Подставляя сумму ряда $S = 2$: $$T(n) = O(n \cdot S) = O(2n) = O(n) \quad \blacksquare$$

[Алгоритм] Пирамидальная сортировка (Heap Sort)

Пирамидальная сортировка упорядочивает массив размера $n$ по неубыванию in-place за $O(n \log n)$:

  1. Фаза 1 (Построение): Вызываем $\mathrm{Heapify}(A)$ для всего массива, превращая его в Max-Heap. Время: $O(n)$. В ячейке $A[0]$ находится абсолютный максимум.
  2. Фаза 2 (Сортировка): Итерируемся $i$ от $n-1$ вниз до $1$:
    • Меняем местами $A[0]$ и $A[i]$. Теперь максимальный элемент неотсортированной части встал на свое итоговое место в конец массива.
    • Уменьшаем размер кучи до $i$ (элемент $A[i]$ теперь считается зафиксированным).
    • Вызываем $\mathrm{siftDown}(0, i)$, восстанавливая свойство Max-Heap на префиксе длины $i$.

Анализ сложности: Фаза 1 требует $O(n)$. В фазе 2 выполняется $n-1$ просеиваний, каждое из которых занимает $O(\log n)$. $$T(n) = O(n) + \sum_{i=1}^{n-1} O(\log i) = O(n \log n)$$ Память: $O(1)$ строго. Сортировка нестабильна (из-за далеких перестановок корня с хвостом).

💻 Реализация Heapify и HeapSort на Java++ 
class HeapSortAlgorithm {
    void siftDown(int[] a, int i, int n) {
        while (2 * i + 1 < n) {
            int left = 2 * i + 1;
            int right = 2 * i + 2;
            int largest = left;

            if (right < n && a[right] > a[left]) {
                largest = right;
            }
            if (a[i] >= a[largest]) {
                break;
            }
            swap(a, i, largest);
            i = largest;
        }
    }

    // Построение Max-Heap за O(n)
    void heapify(int[] a, int n) {
        for (int i = n / 2 - 1; i >= 0; i--) {
            siftDown(a, i, n);
        }
    }

    // Сортировка на месте за O(n log n)
    void heapSort(int[] a, int n) {
        heapify(a, n); // Фаза 1: O(n)

        for (int i = n - 1; i > 0; i--) {
            swap(a, 0, i); // Максимум в конец
            siftDown(a, 0, i); // Восстановление кучи на префиксе i
        }
    }

    void swap(int[] a, int i, int j) {
        int tmp = a[i]; a[i] = a[j]; a[j] = tmp;
    }
}
