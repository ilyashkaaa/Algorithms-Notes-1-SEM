[Мотивация] Устранение худшего случая $O(n^2)$

Классическая быстрая сортировка с рандомизированным выбором опорного элемента работает за ожидаемое время $O(n \log n)$, однако в наихудшем случае деградирует до $O(n^2)$.

Цель: Построить алгоритм быстрой сортировки, который строго детерминированно гарантирует время $O(n \log n)$ в абсолютно наихудшем случае, сохраняя структуру алгоритма QuickSort с процедурой $\mathrm{Partition}$.

[Алгоритм] Быстрая сортировка с медианой медиан

Для отрезка массива $[l, r]$ размера $n = r - l + 1$:

  1. База рекурсии: Если отрезок пуст или содержит один элемент ($l \ge r$), завершаем работу. Для малых отрезков ($n \le 16$) сортируем массив на месте за $O(1)$.
  2. Выбор опорного элемента (Pivot):
    • Разбиваем массив на группы по 5 элементов.
    • В каждой пятерке находим медиану за $O(1)$ (собираем $\lceil n/5 \rceil$ медиан).
    • Рекурсивно находим медиану медиан $M$ (или вызываем линейный детерминированный выбор точной медианы) за время $O(n)$.
  3. Разбиение (Partition): Выполняем процедуру $\mathrm{Partition}$ массива вокруг найденного элемента $M$ на месте ($O(1)$ доп. памяти) за время $O(n)$.
  4. Рекурсивный спуск: Так как медиана медиан гарантирует разделение массива в пропорции не хуже $3:7$ (а при выборе точной медианы — ровно $1:1$), ни один из подмассивов не содержит более $7n/10$ элементов. Рекурсивно вызываем сортировку для левой и правой частей.
[Теорема и Доказательство] Оценка времени работы $O(n \log n)$ в худшем случае

Теорема: Быстрая сортировка с выбором опорного элемента алгоритмом медианы медиан работает в наихудшем случае за детерминированное время $O(n \log n)$.

Доказательство 1 (через выбор точной медианы за $O(n)$):

  • Время нахождения точной медианы детерминированным линейным выбором: $O(n)$.
  • Время выполнения Partition на отрезке размера $n$: $O(n)$.
  • После разбиения массив делится на две равные части размером не более $n/2$.
$$T(n) = 2 \cdot T\left(\frac{n}{2}\right) + O(n)$$

По теореме о рекуррентных соотношениях (или методом развертывания дерева рекурсии): глубина дерева $\log_2 n$, на каждом уровне суммарно выполняется $O(n)$ работы. Следовательно:

$$T(n) = O(n \log n) \quad \text{в наихудшем случае.}$$

Доказательство 2 (непосредственно с медианой медиан в качестве pivot):

Если в качестве pivot берется сама медиана медиан (без полного линейного поиска точной медианы):

  • Нахождение медианы медиан занимает время $T_{\mathrm{MM}}(n) \le T(n/5) + O(n) = O(n)$.
  • Разбиение $\mathrm{Partition}$ гарантирует, что максимальный размер любой из двух частей не превосходит $\frac{7}{10}n$.
  • Максимальная глубина дерева рекурсии ограничена величиной $\log_{10/7} n = \frac{\ln n}{\ln(10/7)} = O(\log n)$.
  • На каждом уровне глубины $k$ суммарная длина всех рассматриваемых подмассивов не превышает исходной длины $n$, поэтому суммарная работа на каждом уровне составляет $O(n)$.
$$T(n) \le \sum_{k=0}^{\log_{10/7} n} O(n) = O(n \log n)$$
[Сравнение] Рандомизированный vs Детерминированный QuickSort

Сопоставление двух подходов к выбору опорного элемента:

  • Рандомизированный QuickSort: Опорный элемент выбирается случайно за $O(1)$. Ожидаемое время работы $\mathbb{E}[T(n)] = O(n \log n)$ с очень маленькой практической константой. Однако существует теоретический наихудший случай $O(n^2)$.
  • Детерминированный QuickSort с медианой медиан: Обеспечивает строгую математическую гарантию $O(n \log n)$ в наихудшем случае без вероятностных предположений. Плата за это — необходимость разбиения на пятерки и нахождения медиан, что увеличивает скрытую константу времени.
[Summary] Сводные характеристики алгоритмов
Алгоритм Среднее время Худшее время Доп. память Особенность

💻 Реализация детерминированного QuickSort с медианой медиан на Java++ 
class DeterministicQuickSort {
    private MedianOfMedians mm = new MedianOfMedians();

    // Гарантированное время O(n log n) в абсолютно худшем случае
    void sort(int[] a, int l, int r) {
        if (l >= r) return;

        // Для малых отрезков используем сортировку вставками
        if (r - l + 1 <= 16) {
            insertionSort(a, l, r);
            return;
        }

        // 1. Находим медиану за детерминированное O(n) через алгоритм медианы медиан
        int midIdx = l + (r - l) / 2;
        int medianValue = mm.select(a, l, r, midIdx);

        // 2. Partition вокруг гарантированного опорного элемента
        int m = partitionValue(a, l, r, medianValue);

        // 3. Рекурсивные вызовы для половин размера <= n / 2
        sort(a, l, m - 1);
        sort(a, m + 1, r);
    }

    int partitionValue(int[] a, int l, int r, int pivot) {
        for (int i = l; i <= r; i++) {
            if (a[i] == pivot) { swap(a, i, r); break; }
        }
        int m = l;
        for (int i = l; i < r; i++) {
            if (a[i] < pivot) { swap(a, m, i); m++; }
        }
        swap(a, m, r);
        return m;
    }

    void insertionSort(int[] a, int l, int r) {
        for (int i = l + 1; i <= r; i++) {
            int cur = a[i], j = i - 1;
            while (j >= l && a[j] > cur) {
                a[j + 1] = a[j];
                j--;
            }
            a[j + 1] = cur;
        }
    }

    void swap(int[] a, int i, int j) {
        int tmp = a[i]; a[i] = a[j]; a[j] = tmp;
    }
}
