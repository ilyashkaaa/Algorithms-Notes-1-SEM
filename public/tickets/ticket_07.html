[Алгоритм] Сортировка слиянием (Merge Sort)

Алгоритм основан на парадигме «разделяй и властвуй» (Divide and Conquer):

  1. Разделение (Divide): Отрезок массива $A[l \dots r]$ делится пополам точкой $m = \lfloor (l + r) / 2 \rfloor$. База рекурсии: при $l \ge r$ массив из $\le 1$ элемента уже отсортирован.
  2. Властвование (Conquer): Рекурсивно вызывается сортировка левой половины $A[l \dots m]$ и правой половины $A[m+1 \dots r]$.
  3. Слияние (Combine): Процедура $\mathrm{Merge}$ сливает две отсортированные половины в один упорядоченный массив с помощью двух указателей за $O(n)$ времени и $O(n)$ дополнительной памяти.

Обеспечение стабильности: При сравнении элементов $Left[i]$ и $Right[j]$, если $Left[i] \le Right[j]$, первым в результирующий массив всегда записывается элемент из левой половины. Это гарантирует строгое сохранение взаимного порядка равных элементов.

[Теорема] Анализ времени работы через дерево рекурсии

Время работы сортировки $n$ элементов описывается рекуррентным соотношением:

$$T(n) = 2 \cdot T\left(\left\lfloor \frac{n}{2} \right\rfloor\right) + \Theta(n), \qquad T(1) = \Theta(1)$$

Доказательство через уровни дерева рекурсии:

  • На уровне $k$ дерева рекурсии находится ровно $2^k$ подзадач, каждая из которых имеет размер $\frac{n}{2^k}$.
  • Суммарное время работы слияния на уровне $k$ равно: $$2^k \cdot O\left(\frac{n}{2^k}\right) = O(n)$$
  • Глубина дерева рекурсии до базового случая размера $1$ составляет $h = \lceil \log_2 n \rceil + 1$.
  • Суммируя по всем $\log_2 n$ уровням, получаем: $$T(n) = \sum_{k=0}^{\lceil \log_2 n \rceil} O(n) = O(n \log n)$$

Время работы составляет $\Theta(n \log n)$ гарантированно во всех случаях (лучший, средний, худший).

[Определение] Инверсия в массиве

Пусть дан числовой массив $A[0 \dots n-1]$. Инверсией называется пара индексов $(i, j)$ такая, что:

$$i < j \quad \text{и} \quad A[i] > A[j]$$

Свойства:

  • В отсортированном по неубыванию массиве число инверсий равно $0$.
  • В массиве, отсортированном по невозрастанию, число инверсий максимально и равно $\frac{n(n-1)}{2} = \Theta(n^2)$.
  • Каждый обмен соседних элементов в пузырьковой сортировке устраняет ровно одну инверсию.
[Алгоритм] Подсчет числа инверсий за $O(n \log n)$

Разобьем массив на левую половину $A[l \dots m]$ и правую половину $A[m+1 \dots r]$. Любая инверсия $(i, j)$ относится ровно к одной из трех категорий:

  1. Оба индекса в левой половине: $l \le i < j \le m$ (число таких инверсий $\mathrm{inv}_{left}$).
  2. Оба индекса в правой половине: $m+1 \le i < j \le r$ (число таких инверсий $\mathrm{inv}_{right}$).
  3. Разделенная инверсия (Cross-inversion): $l \le i \le m < j \le r$, где $A[i] > A[j]$.

Ключевая идея в процедуре слияния:
Пусть обе половины $Left$ и $Right$ уже отсортированы. Если при слиянии элемент $Right[j] < Left[i]$, то поскольку левая половина отсортирована, $Right[j]$ меньше не только $Left[i]$, но и всех последующих элементов левой половины от $i$ до $m$!
Следовательно, к счетчику инверсий прибавляется: $$\Delta = m - i + 1$$ Таким образом, все разделенные инверсии подсчитываются на лету за время $O(n)$ без дополнительных циклов! $$\text{Итоговое время: } O(n \log n), \quad \text{Память: } O(n)$$

💻 Реализация MergeSort с подсчетом инверсий на Java++ 
class MergeSortInv {
    long mergeAndCount(int[] arr, int[] temp, int l, int m, int r) {
        int i = l, j = m + 1, k = l;
        long invCount = 0;

        while (i <= m && j <= r) {
            if (arr[i] <= arr[j]) { // знак <= обеспечивает стабильность
                temp[k++] = arr[i++];
            } else {
                temp[k++] = arr[j++];
                invCount += (m - i + 1); // все оставшиеся в левой половине образуют инверсию
            }
        }
        while (i <= m) temp[k++] = arr[i++];
        while (j <= r) temp[k++] = arr[j++];
        for (i = l; i <= r; i++) arr[i] = temp[i];

        return invCount;
    }

    long sortAndCount(int[] arr, int[] temp, int l, int r) {
        long invCount = 0;
        if (l < r) {
            int m = l + (r - l) / 2;
            invCount += sortAndCount(arr, temp, l, m);
            invCount += sortAndCount(arr, temp, m + 1, r);
            invCount += mergeAndCount(arr, temp, l, m, r);
        }
        return invCount;
    }
}
