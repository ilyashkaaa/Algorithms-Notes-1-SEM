[Определение] Классические префиксные суммы

Пусть дан числовой массив $A[0 \dots n-1]$. Массив префиксных сумм $P[0 \dots n]$ размера $n+1$ определяется соотношением:

$$P[0] = 0, \qquad P[k] = \sum_{i=0}^{k-1} A[i] \quad (1 \le k \le n)$$

Построение (за один проход за $O(n)$): $$P[k] = P[k-1] + A[k-1]$$

Ответ на запрос суммы на подотрезке $[L, R]$ за $O(1)$: $$\sum_{i=L}^{R} A[i] = P[R+1] - P[L]$$

♦ Геометрическая идея принципа включений-исключений

Сумма на подотрезке $[L, R]$ представляет собой разность двух вложенных префиксов: префикса длины $R+1$ (включает всё от начала до $R$) за вычетом лишнего начального префикса длины $L$ (включает элементы от $0$ до $L-1$).

[Теорема] Обобщение на произвольную обратимую операцию (Алгебраическая группа)

Пусть на множестве $G$ задана бинарная операция $\circ$, образующая группу $\langle G, \circ, e, ^{-1} \rangle$:

  1. Ассоциативность: $(a \circ b) \circ c = a \circ (b \circ c)$.
  2. Нейтральный элемент $e$: $\forall a \in G \implies a \circ e = e \circ a = a$.
  3. Обратимость: $\forall a \in G \; \exists a^{-1} \in G$ такой, что $a \circ a^{-1} = a^{-1} \circ a = e$.

Определим массив префиксных произведений: $$P[0] = e, \qquad P[k] = P[k-1] \circ A[k-1] = A[0] \circ A[1] \circ \dots \circ A[k-1]$$

Тогда результат на отрезке $[L, R]$ вычисляется за $O(1)$ через умножение на обратный элемент: $$\prod_{i=L}^R A[i] = (P[L])^{-1} \circ P[R+1]$$

Важнейшие примеры групп:
  • Побитовый XOR ($\oplus$): Обратным к $x$ является сам элемент $x$ ($x \oplus x = 0$). Запрос XOR на отрезке $[L, R]$: $P[R+1] \oplus P[L]$ за $O(1)$.
  • Умножение по модулю простого числа $p$ в $\mathbb{F}_p^*$: Обратный элемент вычисляется за $O(\log p)$ через МТФ: $x^{-1} = x^{p-2} \pmod p$.
[Алгоритмы] Обобщение на необратимые ассоциативные операции (Полугруппы)

Если операция $\circ$ ассоциативна, но необратима (полугруппа $\langle S, \circ \rangle$, например $\min, \max, \gcd$, умножение прямоугольных матриц), то «вычесть» префикс невозможно.

Для вычисления запросов на подотрезках применяются следующие методы:

  • Случай 1: Операция идемпотентна ($x \circ x = x$, например $\min, \max, \gcd$):
    Применяется структура Sparse Table (Разреженная таблица): предподсчет за $O(n \log n)$, ответ на любой запрос за $O(1)$ через объединение двух перекрывающихся подотрезков длины $2^k$.
  • Случай 2: Общая полугруппа (не идемпотентна, например умножение матриц):
    Применяется Дерево отрезков (Segment Tree): построение за $O(n)$, ответ на запрос на произвольном отрезке $[L, R]$ за $O(\log n)$.
  • Случай 3: Блочные префиксы и суффиксы (корневая эвристика):
    Массив разбивается на блоки размера $B = \sqrt{n}$. Для каждого блока считаются префиксные и суффиксные произведения: $pref[i]$ и $suff[i]$. Запрос, пересекающий границы блоков, вычисляется комбинированием суффикса левого блока, промежуточных блоков и префикса правого блока: $$A[L \dots R] = suff[L] \circ (\text{полные блоки}) \circ pref[R]$$
[Доказательство] Корректность вычисления через обратный элемент

Докажем, что $(P[L])^{-1} \circ P[R+1] = A[L] \circ \dots \circ A[R]$.

По определению: $P[R+1] = A[0] \circ \dots \circ A[L-1] \circ A[L] \circ \dots \circ A[R] = P[L] \circ \left(\prod_{i=L}^R A[i]\right)$.

Домножим обе части равенства слева на $(P[L])^{-1}$: $$(P[L])^{-1} \circ P[R+1] = (P[L])^{-1} \circ \left( P[L] \circ \prod_{i=L}^R A[i] \right)$$ В силу ассоциативности переставим скобки: $$(P[L])^{-1} \circ P[R+1] = \left( (P[L])^{-1} \circ P[L] \right) \circ \prod_{i=L}^R A[i] = e \circ \prod_{i=L}^R A[i] = \prod_{i=L}^R A[i] \quad \blacksquare$$

💻 Реализация префиксных сумм и префиксного XOR на Java++ 
class PrefixSum {
    long[] pref;

    PrefixSum(int[] arr, int n) {
        pref = new long[n + 1];
        pref[0] = 0;
        for (int i = 0; i < n; i++) {
            pref[i + 1] = pref[i] + arr[i]; // O(n) построение
        }
    }

    // Сумма на отрезке [l, r] за O(1)
    long query(int l, int r) {
        return pref[r + 1] - pref[l];
    }
}

class PrefixXor {
    int[] pref;

    PrefixXor(int[] arr, int n) {
        pref = new int[n + 1];
        pref[0] = 0;
        for (int i = 0; i < n; i++) {
            pref[i + 1] = pref[i] ^ arr[i];
        }
    }

    // XOR на отрезке [l, r] за O(1)
    int query(int l, int r) {
        return pref[r + 1] ^ pref[l];
    }
}
