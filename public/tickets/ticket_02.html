[Определение] Классический бинарный поиск

Постановка задачи (из лекции): Дан отсортированный массив $A[1 \dots n]$. Требуется проверить, есть ли в нем элемент $X$.

Обозначим за $l = 1$ и $r = n$ левую и правую границы рассматриваемого подмассива.

  1. Если диапазон валиден, то проверяем: $A\left[\left\lceil \frac{l + r}{2} \right\rceil\right] \stackrel{?}{\ge} X$. Иначе возвращаем границу.
  2. Если полученный результат истинен, то запускаем рекурсивно поиск в левой половине массива.
  3. Иначе — запускаем рекурсивно поиск в правой половине массива.

Что делает алгоритм на каждом шаге:

  • Сравнивает средний элемент с $X$ за $O(1)$.
  • Решает, продолжать в левой или правой половине за $O(1)$.
  • Запускается рекурсивно, уменьшая область поиска в два раза.

Результат будет получен, когда длина диапазона станет равной $1$. Всего шагов: $\log_2 n$, а итоговое время: $\log_2 n \cdot O(1) = O(\log n)$.

[Метод] Бинарный поиск по ответу

Определение (из лекции): Пусть имеется монотонный предикат $P(n) \in \{0, 1\}$, то есть: $$\exists N_0 : \begin{cases} P(n) = 0, & n < N_0 \\ P(n) = 1, & n \ge N_0 \end{cases}$$ И перед нами стоит задача отыскать это пороговое значение $N_0$.

Пример из лекции: Задача проверки наличия элемента $X$ в отсортированном массиве. В данном случае предикат имеет вид: $$P(i) = 1 \iff a[i] \ge X$$

Алгоритм: Пусть $N_0$ заведомо лежит в диапазоне $[l; r]$.

  1. Если диапазон валиден, то вычисляем $P\left(\left\lceil \frac{l + r}{2} \right\rceil\right)$. Иначе возвращаем границу.
  2. Если результат истинен, то $N_0 \in \left[l; \left\lceil \frac{l + r}{2} \right\rceil\right]$. Запускаем рекурсивно поиск в левой половине.
  3. Иначе $N_0 \in \left[\left\lceil \frac{l + r}{2} \right\rceil; r\right]$. Запускаем рекурсивно поиск в правой половине.

Сложность алгоритма: $O(\log n)$.

[Алгоритм] Вещественный бинарный поиск

Пример из лекции: Допустим, нужно решить уравнение: $$x + \tan x = 3, \quad x \in \left(0; \frac{\pi}{2}\right)$$

Рассмотрим монотонно возрастающую функцию $f(x) = x + \tan x - 3$ и предикат: $$P(x) = \mathbb{I}(f(x) \ge 0)$$

Применяем бинарный поиск с начальными границами $l = 0, r = \frac{\pi}{2}$.

Условие выхода: $|r - l| < \varepsilon$.

Сложность алгоритма: $$O\left(\log \frac{r - l}{\varepsilon}\right)$$

[Теорема] Формальный анализ через рекуррентные соотношения

Введем функцию $T(n)$ — время решения задачи для массива длины $n$. Так как за константное число операций задача сводится к вдвое меньшей, запишем рекуррентное соотношение: $$T(n) = T\left(\left\lfloor \frac{n}{2} \right\rfloor\right) + 1$$

Метод развертывания рекурренты (из лекции): $$T(n) = T\left(\frac{n}{2}\right) + 1 = \left(T\left(\frac{n}{4}\right) + 1\right) + 1 = T\left(\frac{n}{4}\right) + 2 = \dots = T\left(\frac{n}{2^k}\right) + k$$

Остановка происходит тогда же, когда и в алгоритме: при $n / 2^k \le 1$, то есть при $k = \lceil \log_2 n \rceil$, где $T(1) = 1$: $$T(n) = T\left(\frac{n}{2^{\lceil \log_2 n \rceil}}\right) + \lceil \log_2 n \rceil = 1 + \lceil \log_2 n \rceil \le \log_2 n + 2 = O(\log n)$$

Мастер-теорема (б/д, формулировка из лекции):
Пусть $T(n) = a T(n/b) + f(n)$ при $a \ge 1, b > 1$. Для бинпоиска $a = 1, b = 2, f(n) = 1 = \Theta(n^{\log_2 1})$. Это случай 2 ($f(n) = \Theta(n^{\log_b a})$), откуда $T(n) = \Theta(n^{\log_b a} \log n) = \Theta(\log n)$.

★ Summary билета (ключевые факты)
  • Защита от переполнения: Вычисление середины $M = (L + R) / 2$ при $L + R > 2^{31}-1$ переполняет стандартный знаковый 32-битный `int`. Всегда пишется: $$M = L + \frac{R - L}{2}$$

// 1. Классический LowerBound: первый индекс, где arr[i] >= x
int lowerBound(int[] arr, int n, int x) {
    int l = 0, r = n; // полуинтервал [l, r)
    while (l < r) {
        int m = l + (r - l) / 2; // без переполнения int
        if (arr[m] < x) {
            l = m + 1;
        } else {
            r = m;
        }
    }
    return l; // индекс первого элемента >= x (или n, если такого нет)
}

// 2. Вещественный бинарный поиск по числу итераций
double realBinarySearch(double l, double r) {
    // 80 итераций сокращают отрезок в 2^80 раз (~ 10^24)
    for (int iter = 0; iter < 80; iter++) {
        double m = l + (r - l) / 2.0;
        if (check(m)) {
            l = m; // или r = m в зависимости от монотонности
        } else {
            r = m;
        }
    }
    return l;
}
