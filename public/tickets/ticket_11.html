[Определение] $k$-я порядковая статистика и медиана

$k$-я порядковая статистика ($k$-th Order Statistic) массива $A[0 \dots n-1]$ — это элемент, который оказался бы на $k$-й позиции ($0 \le k < n$), если бы массив был отсортирован в порядке неубывания.

  • При $k = 0$ — минимальный элемент массива ($O(n)$ линейным сканированием).
  • При $k = n - 1$ — максимальный элемент массива ($O(n)$ линейным сканированием).
  • При $k = \lfloor n / 2 \rfloor$ — медиана массива.

Тривиальный подход: Отсортировать массив целиком (MergeSort или HeapSort) за $O(n \log n)$ и вернуть $A[k]$. Задача: научиться находить произвольную $k$-ю порядковую статистику быстрее, за линейное время $O(n)$.

[Алгоритм] Рандомизированный алгоритм Quick Select

Идея опирается на процедуру $\mathrm{Partition}$ из быстрой сортировки, но в отличие от нее, рекурсия спускается только в одну ветвь.

Шаги алгоритма поиска $k$-й статистики на отрезке $[l, r]$:

  1. Если $l = r$, отрезок состоит из одного элемента — возвращаем $A[l]$.
  2. Выбираем опорный элемент $\mathrm{pivot} = A[\mathrm{rnd}(l, r)]$.
  3. Выполняем процедуру $\mathrm{Partition}(A, l, r)$, которая расставляет элементы так, что опорный элемент встает на свою финальную позицию $m$, все элементы левее $m$ не превосходят его ($A[i] \le A[m]$), а правее — не меньше его ($A[j] \ge A[m]$).
  4. Анализ индекса $m$:
    • Если $k = m$, искомый элемент найден — возвращаем $A[m]$.
    • Если $k < m$, искомый элемент строго меньше $A[m]$ и обязан находиться в левом подмассиве $[l, m - 1]$ — рекурсивно ищем $k$-ю статистику на $[l, m - 1]$.
    • Если $k > m$, искомый элемент строго больше $A[m]$ и находится в правом подмассиве $[m + 1, r]$ — рекурсивно ищем $k$-ю статистику на $[m + 1, r]$.
[Теорема] Временная сложность Quick Select

Время работы зависит от качества разбиения массива опорным элементом.

1. Худший случай: $O(n^2)$

Если на каждом шаге в качестве пивота выбирается минимальный (или максимальный) элемент, а целевой индекс $k$ находится на другом конце массива, то размер задачи уменьшается всего на 1:

$$T(n) = T(n - 1) + O(n) = \sum_{i=1}^n O(i) = O(n^2)$$

2. Среднее время со случайным пивотом: $O(n)$

Теорема (без доказательства): Математическое ожидание времени работы алгоритма Quick Select при случайном равновероятном выборе опорного элемента $\mathrm{pivot} \in [l, r]$ составляет:

$$\mathbb{E}[T(n)] = \Theta(n)$$
[Интуиция] Сравнение с QuickSort и геометрическая прогрессия

Почему среднее время QuickSort равно $O(n \log n)$, а QuickSelect — $O(n)$?

  • В QuickSort: алгоритм обязан рекурсивно обработать обе половины. На каждом из $\log_2 n$ уровней суммарный объем данных равен $n$, что суммируется в $\sum_{i=0}^{\log n} n = O(n \log n)$.
  • В QuickSelect: алгоритм отбрасывает одну из половин и спускается ровно в одну часть.

С вероятностью $1/2$ случайно выбранный пивот попадает в межквартильный диапазон (между 25% и 75%), деля массив не хуже чем $1:3$. В этом случае размер оставшейся части не превосходит $\frac{3}{4} n$.

Тогда суммарное число операций оценивается суммой бесконечно убывающей геометрической прогрессии со знаменателем $q \le 3/4$:

$$T(n) \le C n + C \left(\frac{3}{4}\right) n + C \left(\frac{3}{4}\right)^2 n + \dots = C n \cdot \frac{1}{1 - 3/4} = 4 C n = O(n)$$

Даже с учетом неудачных шагов, среднее число шагов до удачного разбиения равно $2$, что лишь увеличивает константу перед линейным слагаемым.

💻 Реализация Quick Select на Java++ (Итеративный вариант, $O(1)$ памяти) 
class QuickSelectAlgorithm {
    private Random rnd = new Random();

    // Поиск k-й порядковой статистики на отрезке [l, r]
    // Среднее время O(n), память O(1)
    int quickSelect(int[] a, int k) {
        int l = 0;
        int r = a.length - 1;

        while (l < r) {
            int pivotIdx = l + rnd.nextInt(r - l + 1);
            int pivot = a[pivotIdx];

            // Схема разбиения Ломуто с вынесением pivot
            swap(a, pivotIdx, r);
            int m = l;
            for (int i = l; i < r; i++) {
                if (a[i] < pivot) {
                    swap(a, m, i);
                    m++;
                }
            }
            swap(a, m, r); // pivot занял точную позицию m

            if (m == k) {
                return a[m];
            } else if (k < m) {
                r = m - 1; // Идем в левую половину
            } else {
                l = m + 1; // Идем в правую половину
            }
        }
        return a[l];
    }

    void swap(int[] a, int i, int j) {
        int tmp = a[i]; a[i] = a[j]; a[j] = tmp;
    }
}
