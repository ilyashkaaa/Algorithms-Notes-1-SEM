[Определение] AVL-дерево

AVL-дерево — самобалансирующееся бинарное дерево поиска, в каждом узле $x$ которого поддерживается инвариант сбалансированности:

Инвариант AVL: Для любой вершины $x$ высоты ее левого и правого поддеревьев отличаются не более чем на единицу:

$$|h(x.\mathrm{left}) - h(x.\mathrm{right})| \le 1$$

Фактор баланса (Balance Factor):

$$\mathrm{bf}(x) = h(x.\mathrm{right}) - h(x.\mathrm{left}) \in \{-1, 0, 1\}$$

где высота пустого дерева считается равной $0$ (или $-1$, если у листа высота $0$), а высота узла равна $h(x) = 1 + \max(h(x.\mathrm{left}), h(x.\mathrm{right}))$.

[Теорема и Доказательство] Глубина AVL-дерева (из лекции 6, слайд 12)

Теорема: Высота AVL-дерева равна $O(\log N)$.

Доказательство: Рассмотрим такую величину как $S(h)$ — минимальное число вершин в AVL-дереве высоты $h$.

Заметим, что верно следующее соотношение:

$$S(h + 2) = S(h + 1) + S(h) + 1$$

Докажем по индукции, что данную рекурренту можно выразить как:

$$S(h) = F_{h+2} - 1$$

где $F_n$ — $n$-е число Фибоначчи ($F_1 = 1, F_2 = 1, F_3 = 2, F_4 = 3, F_5 = 5 \dots$).

  • База: Для $h = 1$ база верна ($S(1) = 1$, $F_{1+2} - 1 = F_3 - 1 = 2 - 1 = 1$).
  • Индукционный переход: Допустим, что $S(n) = F_{n+2} - 1$ для всех $n \le h$. Тогда: $$\begin{aligned} S(h + 1) &= S(h) + S(h - 1) + 1 \\ &= F_{h+2} - 1 + F_{h+1} - 1 + 1 \\ &= F_{h+2} + F_{h+1} - 1 \\ &= F_{h+3} - 1 \end{aligned}$$

Таким образом, так как числа Фибоначчи растут как геометрическая прогрессия $F_k = \Theta(\phi^k)$ (где $\phi = \frac{1 + \sqrt{5}}{2} \approx 1.618$ — золотое сечение):

$$N \ge S(h) = F_{h+2} - 1 = \Theta(\phi^h) \implies h = O(\log N)$$
[Алгоритмы] 4 типа поворотов для восстановления баланса

Если после вставки или удаления фактор баланса узла $x$ стал равен $+2$ или $-2$, баланс восстанавливается локальным переподвешиванием указателей (поворотом) за строго $O(1)$:

1. Малый правый поворот ($\mathrm{rotateRight}(P)$)

Применяется при $\mathrm{bf}(P) = -2$ и $\mathrm{bf}(P.\mathrm{left}) \le 0$ (перевес левого сына влево). Левый сын $L$ становится новым родителем, $P$ становится его правым сыном, а бывшее правое поддерево $L$ переходит в качестве левого поддерева $P$.

2. Малый левый поворот ($\mathrm{rotateLeft}(P)$)

Применяется при $\mathrm{bf}(P) = +2$ и $\mathrm{bf}(P.\mathrm{right}) \ge 0$ (симметричен правому). Правый сын $R$ занимает место $P$, а $P$ уходит в левые сыновья $R$.

3. Большой правый поворот (Big Right / Left-Right Rotation)

Возникает при $\mathrm{bf}(P) = -2$, но у его левого сына $\mathrm{bf}(P.\mathrm{left}) = +1$ (зигзаг: левое поддерево перегружено своим правым потомком). Сводится к суперпозиции двух малых поворотов:

$$P.\mathrm{left} = \mathrm{rotateLeft}(P.\mathrm{left}); \quad \mathrm{return} \ \mathrm{rotateRight}(P);$$

4. Большой левый поворот (Big Left / Right-Left Rotation)

Возникает при $\mathrm{bf}(P) = +2$, но $\mathrm{bf}(P.\mathrm{right}) = -1$ (зигзаг вправо-влево). Сводится к:

$$P.\mathrm{right} = \mathrm{rotateRight}(P.\mathrm{right}); \quad \mathrm{return} \ \mathrm{rotateLeft}(P);$$
[Операции] Реализация и сложность Insert, Erase, Find
  • $\mathrm{Find}(\mathrm{key})$: Обычный спуск по бинарному дереву поиска. Так как высота $h = O(\log n)$, сложность строго $O(\log n)$.
  • $\mathrm{Insert}(\mathrm{key})$: Спускаемся вниз, вставляем лист, затем при возврате из рекурсии пересчитываем $h(x)$ и вызываем процедуру $\mathrm{balance}(x)$.
    Замечание: При вставке для восстановления инварианта во всем дереве достаточно не более одного поворота (малого или большого). Сложность: $O(\log n)$.
  • $\mathrm{Erase}(\mathrm{key})$: Удаляем узел как в обычном BST (заменяя на in-order преемника). При подъеме к корню пересчитываем высоты и балансируем вершины.
    Замечание: При удалении укорочение поддерева может вызвать каскадный дисбаланс, требуя до $O(\log n)$ поворотов вдоль пути к корню. Сложность: $O(\log n)$.
[Summary] Сводные параметры AVL-дерева
Критерий Значение Пояснение
Инвариант баланса $|h_L - h_R| \le 1$ Жесткий баланс по высоте
Худшая высота $h$ $O(\log n)$ Деревья Фибоначчи $S(h) = F_{h+2} - 1$
Число поворотов Insert $\le 1$ Один малый или большой поворот
Число поворотов Erase $O(\log n)$ Может каскадно подниматься к корню
Время операций $O(\log n)$ строго Гарантия worst-case без рандомизации
💻 Реализация AVL-дерева на Java++ (Повороты, Балансировка, Insert, Erase) 
class AVLTree {
    static class Node {
        int key;
        int height = 1;
        Node left, right;
        Node(int key) { this.key = key; }
    }

    private Node root = null;

    private int h(Node n) { return n == null ? 0 : n.height; }
    private int bf(Node n) { return n == null ? 0 : h(n.right) - h(n.left); }
    private void updateH(Node n) { n.height = 1 + Math.max(h(n.left), h(n.right)); }

    // Малый правый поворот
    private Node rotateRight(Node p) {
        Node q = p.left;
        p.left = q.right;
        q.right = p;
        updateH(p);
        updateH(q);
        return q;
    }

    // Малый левый поворот
    private Node rotateLeft(Node q) {
        Node p = q.right;
        q.right = p.left;
        p.left = q;
        updateH(q);
        updateH(p);
        return p;
    }

    // Балансировка узла: восстанавливает |bf| <= 1
    private Node balance(Node n) {
        updateH(n);
        if (bf(n) == 2) {
            if (bf(n.right) < 0) {
                n.right = rotateRight(n.right); // Большой левый поворот
            }
            return rotateLeft(n);
        }
        if (bf(n) == -2) {
            if (bf(n.left) > 0) {
                n.left = rotateLeft(n.left);   // Большой правый поворот
            }
            return rotateRight(n);
        }
        return n;
    }

    // Вставка за O(log n)
    void insert(int key) { root = insertRec(root, key); }
    private Node insertRec(Node n, int key) {
        if (n == null) return new Node(key);
        if (key < n.key) n.left = insertRec(n.left, key);
        else if (key > n.key) n.right = insertRec(n.right, key);
        return balance(n);
    }

    // Удаление за O(log n)
    void erase(int key) { root = eraseRec(root, key); }
    private Node eraseRec(Node n, int key) {
        if (n == null) return null;
        if (key < n.key) n.left = eraseRec(n.left, key);
        else if (key > n.key) n.right = eraseRec(n.right, key);
        else {
            if (n.left == null) return n.right;
            if (n.right == null) return n.left;
            Node succ = n.right;
            while (succ.left != null) succ = succ.left;
            n.key = succ.key;
            n.right = eraseRec(n.right, succ.key);
        }
        return balance(n);
    }
}
