[Определение] Бинарная пирамида (Двоичная куча)

Бинарной пирамидой (Binary Heap) называется структура данных, удовлетворяющая двум инвариантам одновременно:

  1. Свойство формы (структурное свойство): Дерево является почти полным бинарным деревом. Все уровни, кроме, возможно, последнего, полностью заполнены вершинами. На последнем уровне листья расположены максимально плотно слева направо без пропусков.
  2. Свойство кучи (Heap Property): Для любого узла $v$, отличного от корня:
    • В Min-Heap (куча на минимум): значение в узле не меньше значения его родителя: $\mathrm{val}(v) \ge \mathrm{val}(\mathrm{parent}(v))$. В корне всегда минимум.
    • В Max-Heap (куча на максимум): значение в узле не превосходит значения его родителя: $\mathrm{val}(v) \le \mathrm{val}(\mathrm{parent}(v))$. В корне всегда максимум.
♦ Представление почти полного дерева в виде массива

Благодаря структурному свойству куча не требует хранения явных указателей на детей и родителей! Вершины нумеруются по уровням слева направо и размещаются в обычном непрерывном массиве $A[0 \dots n-1]$:

  • Корень расположен в ячейке $A[0]$.
  • Для узла с индексом $i$:
    • Родитель: $\mathrm{parent}(i) = \left\lfloor \frac{i - 1}{2} \right\rfloor$ (при $i > 0$).
    • Левый сын: $\mathrm{left}(i) = 2i + 1$.
    • Правый сын: $\mathrm{right}(i) = 2i + 2$.
  • Узел является листом $\iff 2i + 1 \ge n$. Листья занимают ровно вторую половину массива: индексы от $\lfloor n/2 \rfloor$ до $n-1$.
[Процедуры] Поддержка свойства пирамиды: SiftUp и SiftDown

1. Просеивание вверх (SiftUp):

Применяется, когда в позицию $i$ помещен элемент, нарушающий инвариант кучи со своим предком (в Min-Heap: $A[i] < A[\mathrm{parent}(i)]$).
Алгоритм: Пока $i > 0$ и $A[i] < A[\mathrm{parent}(i)]$, меняем местами $A[i]$ и $A[\mathrm{parent}(i)]$, после чего переходим к родителю $i \gets \mathrm{parent}(i)$.
Время работы: $O(h) = O(\log n)$.

2. Просеивание вниз (SiftDown):

Применяется, когда значение $A[i]$ больше значений своих сыновей, но поддеревья левого и правого сыновей являются корректными кучами.
Алгоритм: Находим индекс наименьшего из сыновей $\mathrm{smallest} = \arg\min(A[i], A[2i+1], A[2i+2])$. Если $\mathrm{smallest} \ne i$, меняем местами $A[i]$ и $A[\mathrm{smallest}]$, и рекурсивно продолжаем просеивание от индекса $\mathrm{smallest}$.
Время работы: $O(h) = O(\log n)$.

[Операции] Базовые операции очереди с приоритетом

1. GetMin(): Вернуть значение в корне $A[0]$. Сложность: $O(1)$.

2. Insert(x):

  • Добавляем элемент $x$ в конец массива в позицию $A[n]$ (на самое левое свободное место нижнего уровня).
  • Увеличиваем размер кучи $n \gets n + 1$.
  • Вызываем $\mathrm{siftUp}(n - 1)$. Сложность: $O(\log n)$.

3. ExtractMin():

  • Сохраняем минимальный элемент $\mathrm{min\_val} = A[0]$.
  • Переносим последний элемент массива на место корня: $A[0] = A[n - 1]$.
  • Уменьшаем размер кучи $n \gets n - 1$.
  • Восстанавливаем инвариант вызовом $\mathrm{siftDown}(0)$.
  • Возвращаем сохраненный $\mathrm{min\_val}$. Сложность: $O(\log n)$.
[Теорема] Логарифмическая высота бинарной пирамиды

Теорема: Высота двоичной кучи из $n$ элементов равна:

$$h = \lfloor \log_2 n \rfloor = \Theta(\log n)$$

Доказательство: В почти полном бинарном дереве уровни с номерами $0, 1, \dots, h-1$ полностью заполнены, причем на уровне $k$ находится ровно $2^k$ вершин. На последнем уровне $h$ находится от $1$ до $2^h$ вершин. Суммируя геометрическую прогрессию: $$n \ge 1 + 2 + 4 + \dots + 2^{h-1} + 1 = (2^h - 1) + 1 = 2^h$$ $$n \le 1 + 2 + 4 + \dots + 2^{h-1} + 2^h = 2^{h+1} - 1 < 2^{h+1}$$ Логарифмируя двойное неравенство $2^h \le n < 2^{h+1}$: $$h \le \log_2 n < h + 1 \implies h = \lfloor \log_2 n \rfloor$$ Так как операции $\mathrm{siftUp}$ и $\mathrm{siftDown}$ проходят не более одного пути от корня до листа длины $\le h$, их сложность в худшем случае строго ограничена $O(\log n)$. $\blacksquare$

💻 Реализация Min-Heap на Java++ 
class BinaryHeap {
    int[] a;
    int size = 0;

    BinaryHeap(int capacity) {
        a = new int[capacity];
    }

    void siftUp(int i) {
        while (i > 0 && a[i] < a[(i - 1) / 2]) {
            swap(i, (i - 1) / 2);
            i = (i - 1) / 2;
        }
    }

    void siftDown(int i) {
        while (2 * i + 1 < size) {
            int left = 2 * i + 1;
            int right = 2 * i + 2;
            int smallest = left;

            if (right < size && a[right] < a[left]) {
                smallest = right;
            }
            if (a[i] <= a[smallest]) {
                break;
            }
            swap(i, smallest);
            i = smallest;
        }
    }

    void insert(int val) {
        a[size] = val;
        size++;
        siftUp(size - 1);
    }

    int extractMin() {
        int minVal = a[0];
        a[0] = a[size - 1];
        size--;
        siftDown(0);
        return minVal;
    }

    void swap(int i, int j) {
        int tmp = a[i]; a[i] = a[j]; a[j] = tmp;
    }
}
