[Операция] Поиск Find(key) в Splay-дереве

Поиск ключа выполняется как в классическом бинарном дереве поиска, но с обязательной процедурой перебалансировки в конце:

  • Спускаемся от корня вниз, сравнивая $\mathrm{key}$ с ключами узлов.
  • Если ключ найден: вызываем $\mathrm{Splay}(\mathrm{найденный\ узел})$. Найденный элемент становится новым корнем дерева. Возвращаем $\mathrm{true}$.
  • Если ключ отсутствует: путь поиска завершается на $\mathrm{null}$. Вызываем $\mathrm{Splay}(\mathrm{последний\ посещенный\ узел})$ (непосредственный предок несостоявшегося ключа). Предок поднимается в корень, сжимая пройденный путь. Возвращаем $\mathrm{false}$.
Благодаря операции Splay даже неудачные поиски укорачивают ветви дерева, предотвращая деградацию структуры.
[Алгоритмы] Выразимость Split и Merge через Splay

Операция $\mathrm{Splay}$ позволяет реализовать разделение и слияние деревьев предельно лаконично и без рекурсии:

1. Слияние: $\mathrm{Merge}(T_1, T_2)$

Предусловие: Все ключи дерева $T_1$ строго меньше любого ключа дерева $T_2$ ($\forall u \in T_1, v \in T_2: u.\mathrm{key} < v.\mathrm{key}$).

  1. Если одно из деревьев пусто — возвращаем второе.
  2. В дереве $T_1$ находим максимальный элемент (идем вправо до упора) и вызываем для него $\mathrm{Splay}(M)$ внутри дерева $T_1$.
  3. После подъема элемент $M$ становится корнем $T_1$. Так как $M$ был максимальным в $T_1$, у него гарантированно отсутствует правый ребенок ($M.\mathrm{right} == \mathrm{null}$)!
  4. Просто привязываем дерево $T_2$ в качестве правого ребенка $M$: $$M.\mathrm{right} = T_2; \quad T_2.\mathrm{parent} = M;$$
  5. Возвращаем объединенное дерево с корнем $M$.

2. Разделение: $\mathrm{Split}(T, \mathrm{key}) \to (T_1, T_2)$

Разделяет дерево на $T_1$ (ключи $\le \mathrm{key}$) и $T_2$ (ключи $> \mathrm{key}$):

  1. Вызываем $\mathrm{Find}(\mathrm{key})$ в дереве $T$. В корне оказывается либо сам элемент с ключом $\mathrm{key}$, либо ближайший к нему предок.
  2. Если корень $R.\mathrm{key} \le \mathrm{key}$:
    Все элементы правого поддерева $R.\mathrm{right}$ строго больше $\mathrm{key}$. Отрезаем правое поддерево: $$T_2 = R.\mathrm{right}; \quad R.\mathrm{right} = \mathrm{null}; \quad T_1 = R;$$
  3. Если корень $R.\mathrm{key} > \mathrm{key}$:
    Все элементы левого поддерева $R.\mathrm{left}$ меньше либо равны $\mathrm{key}$. Отрезаем левое поддерево: $$T_1 = R.\mathrm{left}; \quad R.\mathrm{left} = \mathrm{null}; \quad T_2 = R;$$
[Алгоритмы] Выразимость Insert и Erase через Split и Merge

1. Вставка: $\mathrm{Insert}(\mathrm{key})$

Операция добавления выражается в 3 строки:

  1. Разрезаем текущее дерево: $(T_1, T_2) = \mathrm{Split}(T, \mathrm{key})$.
  2. Создаем новый узел $N = \mathrm{new\ Node}(\mathrm{key})$.
  3. Подвешиваем $T_1$ левым сыном, а $T_2$ — правым сыном $N$: $$N.\mathrm{left} = T_1; \quad N.\mathrm{right} = T_2; \quad T = N;$$

2. Удаление: $\mathrm{Erase}(\mathrm{key})$

Удаление без разбора частных случаев:

  1. Вызываем $\mathrm{Find}(\mathrm{key})$. Если ключа нет в дереве — завершаем работу.
  2. Если ключ есть, он находится непосредственно в корне дерева $R$!
  3. Отсоединяем поддеревья корня: $T_1 = R.\mathrm{left}, T_2 = R.\mathrm{right}$.
  4. Удаляем корневой узел $R$, а поддеревья объединяем: $$T = \mathrm{Merge}(T_1, T_2)$$
[Теорема] Амортизированная сложность всех операций $O(\log n)$

Теорема (Лекция 7, Кулапин): Все базовые операции над Splay-деревом ($\mathrm{Find}$, $\mathrm{Insert}$, $\mathrm{Erase}$, $\mathrm{Split}$, $\mathrm{Merge}$) выполняются за амортизированное время $O(\log n)$.

Доказательство:

  • $\mathrm{Find}$ состоит из обычного спуска и одного вызова $\mathrm{Splay}$, чье амортизированное время по Лемме о доступе $\le 3 \log_2 n + 1 = O(\log n)$.
  • $\mathrm{Split}$ состоит из одного вызова $\mathrm{Find}$ ($O(\log n)$) и отсоединения указателя за $O(1)$. Отделение поддерева только уменьшает размеры предков, следовательно, потенциал $\Phi$ уменьшается ($\Delta\Phi \le 0$).
  • $\mathrm{Merge}$ выполняет поиск максимума и $\mathrm{Splay}$ в $T_1$ ($O(\log n)$), а последующее присоединение $T_2$ увеличивает ранг только одного узла (нового корня) не более чем на $\log_2 n$. Суммарная учетная стоимость: $O(\log n)$.
  • $\mathrm{Insert}$ и $\mathrm{Erase}$ выражаются через один $\mathrm{Split}$ или $\mathrm{Merge}$, сохраняя амортизированную оценку $O(\log n)$.
[Summary] Операции Splay-дерева через Split и Merge
Операция Амортизированное время Схема реализации
Find(key) $O(\log n)$ BST поиск + Splay найденного узла в корень
Merge(T1, T2) $O(\log n)$ Splay(max in T1), затем T1.right = T2
Split(T, key) $O(\log n)$ Find(key) + отрезание левого/правого сына корня
Insert(key) $O(\log n)$ Split(key) $\to$ новый узел корнем над T1 и T2
Erase(key) $O(\log n)$ Find(key) $\to$ удаление корня $\to$ Merge(left, right)
💻 Полная реализация Splay-дерева (Split, Merge, Insert, Erase, Find) на Java++ 
class SplayTree {
    static class Node {
        int key;
        Node left, right, parent;
        Node(int key) { this.key = key; }
    }

    private Node root = null;

    private void rotate(Node x) {
        Node p = x.parent, g = p.parent;
        boolean isLeft = (x == p.left);
        if (isLeft) {
            p.left = x.right;
            if (x.right != null) x.right.parent = p;
            x.right = p;
        } else {
            p.right = x.left;
            if (x.left != null) x.left.parent = p;
            x.left = p;
        }
        p.parent = x; x.parent = g;
        if (g != null) {
            if (p == g.left) g.left = x; else g.right = x;
        }
    }

    private void splay(Node x) {
        if (x == null) return;
        while (x.parent != null) {
            Node p = x.parent, g = p.parent;
            if (g == null) rotate(x);
            else if ((x == p.left) == (p == g.left)) { rotate(p); rotate(x); }
            else { rotate(x); rotate(x); }
        }
        root = x;
    }

    // Поиск элемента с подъемом в корень: O(log n) аморт.
    boolean find(int key) {
        Node cur = root, last = null;
        while (cur != null) {
            last = cur;
            if (key == cur.key) { splay(cur); return true; }
            cur = (key < cur.key) ? cur.left : cur.right;
        }
        splay(last);
        return false;
    }

    // Слияние двух деревьев: T1 < T2
    private Node merge(Node t1, Node t2) {
        if (t1 == null) return t2;
        if (t2 == null) return t1;
        Node maxNode = t1;
        while (maxNode.right != null) maxNode = maxNode.right;
        splay(maxNode); // maxNode стал корнем t1, у него нет правого сына!
        maxNode.right = t2;
        t2.parent = maxNode;
        return maxNode;
    }

    // Вставка ключа: O(log n) аморт.
    void insert(int key) {
        if (root == null) { root = new Node(key); return; }
        find(key); // Поднимает ближайший узел в корень
        if (root.key == key) return; // Уже есть

        Node node = new Node(key);
        if (key < root.key) {
            node.right = root;
            node.left = root.left;
            if (root.left != null) root.left.parent = node;
            root.left = null;
            root.parent = node;
        } else {
            node.left = root;
            node.right = root.right;
            if (root.right != null) root.right.parent = node;
            root.right = null;
            root.parent = node;
        }
        root = node;
    }

    // Удаление ключа через Splay и Merge: O(log n) аморт.
    void erase(int key) {
        if (!find(key)) return; // Ключа нет
        // Удаляемый элемент теперь в root!
        Node t1 = root.left, t2 = root.right;
        if (t1 != null) t1.parent = null;
        if (t2 != null) t2.parent = null;
        root = merge(t1, t2);
    }
}
