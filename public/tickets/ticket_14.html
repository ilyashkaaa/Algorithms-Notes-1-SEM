[Постановка задачи] Детерминированный линейный выбор

Входные данные: Массив $A[0 \dots n-1]$ из $n$ сравнимых элементов и целое число $k$ ($0 \le k < n$).

Цель: Найти $k$-ю порядковую статистику (элемент, который находился бы на позиции $k$, если бы массив был отсортирован).

Проблема рандомизированного QuickSelect: При неудачном выборе опорных элементов рандомизированный выбор работает за худшее время $O(n^2)$. Задача — построить строго детерминированный алгоритм, гарантирующий работу за время $O(n)$ в абсолютно наихудшем случае.

[Алгоритм] Детерминированный Select (с медианой медиан)

Алгоритм $\mathrm{DeterministicSelect}(A, l, r, k)$ для поиска на отрезке $[l, r]$:

  1. База: Если длина отрезка $n = r - l + 1 \le 5$, сортируем отрезок на месте вставками и сразу возвращаем элемент $A[k]$ за $O(1)$.
  2. Вычисление пивота (медианы медиан):
    • Разбиваем отрезок на $\lceil n/5 \rceil$ блоков по 5 элементов.
    • Сортируем каждую пятерку за константное время и помещаем ее медиану в начало отрезка (in-place сборка медиан).
    • Рекурсивно находим медиану массива собранных медиан: $$M = \mathrm{DeterministicSelect}\left(A, l, l + \lceil n/5 \rceil - 1, l + \lfloor \lceil n/5 \rceil / 2 \rfloor\right)$$
  3. Разбиение Partition: Выполняем процедуру разбиения массива $[l, r]$ по значению $M$. Пусть элемент $M$ встал на индекс $m$.
  4. Шаг ветвления:
    • Если $m = k$, опорный элемент $M$ занял свою окончательную позицию — возвращаем $A[m]$.
    • Если $k < m$, искомый элемент меньше $M$ — рекурсивно запускаемся от левой части: $\mathrm{DeterministicSelect}(A, l, m - 1, k)$.
    • Если $k > m$, искомый элемент больше $M$ — рекурсивно запускаемся от правой части: $\mathrm{DeterministicSelect}(A, m + 1, r, k)$.
[Теорема и Доказательство] Линейная сложность в худшем случае

Теорема: Алгоритм детерминированного выбора порядковой статистики с медианой медиан работает за время $O(n)$ в абсолютно худшем случае.

Доказательство: Время работы $T(n)$ складывается из четырех компонент:

  1. Разбиение на пятерки и поиск их медиан: $\le c_1 n$.
  2. Рекурсивный поиск медианы среди $n/5$ медиан: $T(n/5)$.
  3. Процедура разбиения Partition на отрезке длины $n$: $\le c_2 n$.
  4. Рекурсивный поиск на следующем шаге: так как медиана медиан гарантированно превосходит не менее $3n/10$ элементов и не превосходит не менее $3n/10$ элементов, размер оставшейся подзадачи не превышает $\frac{7n}{10}$. Время этого шага: $T(7n/10)$.

Объединяя константы $c = c_1 + c_2$, получаем рекуррентность:

$$T(n) \le T\left(\frac{n}{5}\right) + T\left(\frac{7n}{10}\right) + cn$$

Методом математической индукции с гипотезой $T(n) \le 10 c n$:

$$T(n) \le 10 c \left(\frac{n}{5}\right) + 10 c \left(\frac{7n}{10}\right) + cn = 2 c n + 7 c n + cn = 10 c n$$
Так как сумма коэффициентов $\frac{1}{5} + \frac{7}{10} = \frac{9}{10} < 1$, рекуррентное дерево сжимается экспоненциально, гарантируя строгое время $O(n)$ без вероятностных оговорок.
[Память] Анализ пространственной сложности

Дополнительная память алгоритма:

  • Память под массив: При in-place перестановке медиан пятерок в начало рабочего диапазона дополнительная динамическая память не требуется: $O(1)$.
  • Стек вызовов: Рекурсивный спуск состоит из двух типов вызовов: первый вызов (нахождение медианы медиан) уменьшает размер задачи в 5 раз, а второй (спуск в нужную часть после Partition) уменьшает размер задачи как минимум в $10/7$ раз.
  • Следовательно, максимальная глубина дерева вызовов ограничена $O(\log n)$, и требуемая память стека составляет $O(\log n)$.

💻 Реализация детерминированного поиска $k$-й статистики на Java++ 
class DeterministicSelect {
    // Поиск k-й порядковой статистики на отрезке [l, r] за гарантированное O(n)
    int select(int[] a, int l, int r, int k) {
        while (r - l + 1 > 5) {
            // 1. Находим медиану медиан
            int numMedians = 0;
            for (int i = l; i <= r; i += 5) {
                int subR = Math.min(i + 4, r);
                insertionSort(a, i, subR);
                int medianIdx = i + (subR - i) / 2;
                swap(a, l + numMedians, medianIdx);
                numMedians++;
            }

            // Рекурсивно находим пивот M среди собранных медиан
            int pivot = select(a, l, l + numMedians - 1, l + numMedians / 2);

            // 2. Partition вокруг pivot M
            int m = partitionValue(a, l, r, pivot);

            // 3. Сужение рабочего диапазона
            if (m == k) {
                return a[m];
            } else if (k < m) {
                r = m - 1;
            } else {
                l = m + 1;
            }
        }

        // Для остатка <= 5 сортируем вставками
        insertionSort(a, l, r);
        return a[k];
    }

    int partitionValue(int[] a, int l, int r, int pivot) {
        for (int i = l; i <= r; i++) {
            if (a[i] == pivot) { swap(a, i, r); break; }
        }
        int m = l;
        for (int i = l; i < r; i++) {
            if (a[i] < pivot) { swap(a, m, i); m++; }
        }
        swap(a, m, r);
        return m;
    }

    void insertionSort(int[] a, int l, int r) {
        for (int i = l + 1; i <= r; i++) {
            int cur = a[i], j = i - 1;
            while (j >= l && a[j] > cur) {
                a[j + 1] = a[j];
                j--;
            }
            a[j + 1] = cur;
        }
    }

    void swap(int[] a, int i, int j) {
        int tmp = a[i]; a[i] = a[j]; a[j] = tmp;
    }
}
