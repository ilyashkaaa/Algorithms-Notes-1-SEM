[Алгоритм] Классическое решето Эратосфена за $O(n \log \log n)$

Постановка задачи: Найти все простые числа в диапазоне от $2$ до $n$.

Алгоритм:

  1. Инициализируем булев массив $\mathrm{isPrime}[0 \dots n]$ значениями $\mathrm{true}$, за исключением $0$ и $1$.
  2. Перебираем числа $p$ от $2$ до $\lfloor \sqrt{n} \rfloor$. Если $\mathrm{isPrime}[p] == \mathrm{true}$, вычеркиваем все составные числа, кратные $p$, начиная с $p^2$: $$i = p^2, \; p^2 + p, \; p^2 + 2p, \; \dots \le n$$ Оптимизация старта с $p^2$: Любое составное кратное $k \cdot p$ при $k < p$ уже гарантированно было вычеркнуто минимальным простым делителем числа $k$.

Временная сложность (б/д): Общее число вычеркиваний оценивается суммой по простым числам (по теореме Мертенса $\sum_{p \le n} \frac{1}{p} = \ln \ln n + M + O(1/\ln n)$): $$T(n) = \sum_{p \le n, \; p \text{ prime}} \frac{n}{p} = n \sum_{p \le n} \frac{1}{p} = O(n \log \log n)$$ Память: $O(n)$ бит.

♦ Причина сублинейности: повторные вычеркивания

Классическое решето тратит лишнее время, потому что одно и то же составное число вычеркивается многократно: число $6$ вычеркивается двойкой и тройкой, число $30$ вычеркивается $2, 3$ и $5$, а число $2310$ — пятью различными простыми. Чтобы достичь строго линейного времени $O(n)$, нужно гарантировать, что каждое составное число вычеркивается ровно один раз.

[Алгоритм] Линейное решето Эратосфена за $O(n)$

Основная идея: Каждое составное число $x$ представляется в виде $x = p \cdot i$, где $p = lp[x]$ — наименьший простой делитель (least prime) числа $x$. Алгоритм вычеркивает число $x$ ровно в тот момент, когда внешний цикл доходит до сомножителя $i$.

Структуры данных:

  • Массив $lp[2 \dots n]$, где $lp[i]$ — минимальный простой делитель числа $i$ (инициализирован нулями).
  • Список найденных простых чисел $\mathrm{primes}$.

Шаги алгоритма:

  1. Итерируемся $i$ от $2$ до $n$. Если $lp[i] == 0$, значит число $i$ простое: записываем $lp[i] = i$ и добавляем $i$ в $\mathrm{primes}$.
  2. Перебираем простые числа $p \in \mathrm{primes}$ такие, что $p \le lp[i]$ и $p \cdot i \le n$:
    • Помечаем составное число: $lp[p \cdot i] = p$.
    • Ключевая точка останова: Если $p == lp[i]$, немедленно прерываем внутренний цикл (`break`)!
[Теорема и Доказательство] Линейность времени работы $O(n)$

Теорема: Линейное решето Эратосфена находит все простые числа от $2$ до $n$ и корректно заполняет массив $lp$ ровно за $O(n)$ операций.

Доказательство корректности и единственности вычеркивания:

  1. Пусть $x$ — произвольное составное число $\le n$, и пусть $p = lp[x]$ — его наименьший простой делитель. Представим $x = p \cdot i$.
  2. Так как $p$ — наименьший простой делитель числа $x$, а $i = x / p$, то все простые делители числа $i$ не меньше $p$, то есть $p \le lp[i]$.
  3. Следовательно, на шаге внешнего цикла, равном $i$, число $p$ обязательно встретится во внутреннем цикле (так как $p \le lp[i]$), и число $x = p \cdot i$ будет помечено: $lp[x] = p$.
  4. Зачем нужен `break` при $p == lp[i]$?
    Если бы мы продолжили цикл для следующего простого $p' > p = lp[i]$, то для составного числа $y = p' \cdot i$ наименьшим простым делителем уже не являлось бы $p'$, поскольку $y$ делится на $lp[i] = p < p'$. Число $y$ обязано быть вычеркнуто позже своим истинным минимальным делителем $p$.

Оценка времени: Каждое составное число $x \in [2, n]$ помечается ровно один раз через пару $(p, i) = (lp[x], x / lp[x])$. Таким образом, тело внутреннего цикла выполняется не более $n$ раз. $$\text{Время работы: } T(n) = \Theta(n), \quad \text{Память: } O(n)$$

[Применение] Факторизация за $O(\log x)$ с помощью массива $lp$

Построенный массив минимальных простых делителей $lp$ позволяет факторизовать любое число $x \le n$ за время, пропорциональное количеству его простых делителей, то есть не более $O(\log x)$: 

// Факторизация за O(log x)
while (x > 1) {
    int p = lp[x];
    factors.add(p);
    x /= p;
}

💻 Реализация линейного и классического решета на Java++ 
// 1. Линейное решето Эратосфена за O(n)
class LinearSieve {
    int[] lp;           // lp[i] - минимальный простой делитель
    List<Integer> primes; // список простых чисел

    LinearSieve(int n) {
        lp = new int[n + 1];
        primes = new ArrayList<>();

        for (int i = 2; i <= n; i++) {
            if (lp[i] == 0) {
                lp[i] = i;
                primes.add(i);
            }
            for (int p : primes) {
                if (p > lp[i] || (long)p * i > n) {
                    break;
                }
                lp[p * i] = p; // p - гарантированно минимальный делитель (p*i)
            }
        }
    }
}

// 2. Классическое решето Эратосфена за O(n log log n)
boolean[] classicSieve(int n) {
    boolean[] isPrime = new boolean[n + 1];
    Arrays.fill(isPrime, true);
    isPrime[0] = isPrime[1] = false;

    for (int p = 2; p * p <= n; p++) {
        if (isPrime[p]) {
            for (int i = p * p; i <= n; i += p) {
                isPrime[i] = false;
            }
        }
    }
    return isPrime;
}
