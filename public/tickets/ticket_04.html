[Алгоритм] Факторизация числа за $O(\sqrt{n})$

По основной теореме арифметики любое целое число $n > 1$ единственным образом представляется в виде канонического произведения простых сомножителей: $$n = p_1^{a_1} \cdot p_2^{a_2} \cdots p_k^{a_k}, \quad p_1 < p_2 < \dots < p_k, \; a_i \ge 1$$

Лемма о наименьшем делителе: Если у числа $n$ есть делитель $d > 1$, то наименьший нетривиальный делитель является простым и не превосходит $\lfloor \sqrt{n} \rfloor$.

Алгоритм: Перебираем потенциальные делители $d$ от $2$ до $\lfloor \sqrt{n} \rfloor$. Если $d$ делит $n$, делим $n$ на $d$ до тех пор, пока оно делится, подсчитывая степень $a_i$. Если после цикла $n > 1$, оставшееся значение само является простым множителем в первой степени. $$\text{Временная сложность: } O(\sqrt{n}), \quad \text{Память: } O(1)$$

[Определение] Функция Эйлера $\varphi(n)$

Функцией Эйлера $\varphi(n)$ называется количество натуральных чисел от $1$ до $n$, взаимно простых с $n$: $$\varphi(n) = \big| \{ k \in \mathbb{N} \mid 1 \le k \le n, \; \gcd(k, n) = 1 \} \big|$$

Базовые свойства:

  • Для простого $p$: $\varphi(p) = p - 1$ (все числа $1, \dots, p-1$ взаимно просты с $p$).
  • Для степени простого $p^a$: Числами от $1$ до $p^a$, не взаимно простыми с $p^a$, являются числа, кратные $p$: $1p, 2p, \dots, p^{a-1}p$. Их ровно $p^{a-1}$. Следовательно: $$\varphi(p^a) = p^a - p^{a-1} = p^a \left(1 - \frac{1}{p}\right)$$
  • Мультипликативность: Если $\gcd(a, b) = 1$, то $\varphi(ab) = \varphi(a) \cdot \varphi(b)$.
Сводимость к факторизации: Зная факторизацию $n = \prod_{i=1}^k p_i^{a_i}$, по мультипликативности получаем точную аналитическую формулу: $$\varphi(n) = \prod_{i=1}^k \varphi(p_i^{a_i}) = \prod_{i=1}^k p_i^{a_i}\left(1 - \frac{1}{p_i}\right) = n \prod_{p \mid n} \left(1 - \frac{1}{p}\right)$$ Сложность вычисления: $O(\sqrt{n})$ времени (параллельно с факторизацией) и $O(1)$ памяти.
[Определение] Кольцо $\mathbb{Z}_m$ и обратимость (из лекции)

Определение кольца (интуитивное из лекции): Набор из множества «чисел» и операций сложения и умножения, для которых верны классические свойства (ассоциативность, коммутативность, дистрибутивность), однако нет обратимости по умножению (нельзя делить).

Кольцо $\mathbb{Z}_m$: Структура над числами $\{0, 1, \dots, m-1\}$, где все операции ведутся по модулю $m$.

Пример из лекции ($\mathbb{Z}_6$): Числа $\{0, 1, 2, 3, 4, 5\}$. Вычислим $5 \cdot 4 + 3 \cdot 2$:
$5 \cdot 4 = 20 \equiv 2 \pmod 6$, а $3 \cdot 2 = 6 \equiv 0 \pmod 6$, откуда результат равен $2$ в $\mathbb{Z}_6$.

Отрицательное число в $\mathbb{Z}_m$: $$-b = \begin{cases} 0, & b = 0 \\ m - b, & b \ne 0 \end{cases}$$ Например, вычитание $2 - 4$ в $\mathbb{Z}_6$ интерпретируется как $2 + (-4) = 2 + (6 - 4) = 2 + 2 = 4$.

Деление в $\mathbb{Z}_m$: По определению $a^{-1} = b$ в $\mathbb{Z}_m \iff a \cdot b \equiv 1 \pmod m$.

  • В $\mathbb{Z}_5$: $3^{-1} = 2$, так как $3 \cdot 2 = 6 \equiv 1 \pmod 5$.
  • В $\mathbb{Z}_6$: для любого $k$ произведение $3 \cdot k \pmod 6 \in \{0, 3\} \ne 1$, то есть обратного к $3$ в $\mathbb{Z}_6$ не существует.
[Теоремы] Малая теорема Ферма и теорема Эйлера (б/д)

1. Теорема Эйлера: Пусть $m \in \mathbb{N}$, $a \in \mathbb{Z}$ и $\gcd(a, m) = 1$. Тогда:

$$a^{\varphi(m)} \equiv 1 \pmod m$$

2. Малая теорема Ферма (частный случай при простом $m = p$): Пусть $p$ — простое число, $\gcd(a, p) = 1$. Так как $\varphi(p) = p - 1$, то:

$$a^{p-1} \equiv 1 \pmod p \implies a^p \equiv a \pmod p$$
[Методы] Поиск обратного элемента по модулю

Метод 1: Через теорему Эйлера / МТФ (бинарное возведение в степень):

Так как $a \cdot a^{\varphi(m) - 1} \equiv a^{\varphi(m)} \equiv 1 \pmod m$, то обратный элемент равен: $$a^{-1} \equiv a^{\varphi(m) - 1} \pmod m$$ Если модуль $p$ — простое число: $$a^{-1} \equiv a^{p - 2} \pmod p$$ Вычисляется за $O(\log m)$ умножений алгоритмом быстрого бинарного возведения в степень.

Метод 2: Расширенный алгоритм Евклида (вывод из лекции):

Рассмотрим уравнение $a x + b y = \gcd(a, b)$. Пусть найдено решение $(x_1, y_1)$ для пары $(b \bmod a, a)$.
Так как $b \bmod a = b - \lfloor b/a \rfloor \cdot a$, подставим это в уравнение: $$\left(b - \left\lfloor \frac{b}{a} \right\rfloor \cdot a\right) x_1 + a y_1 = \gcd(a, b)$$ Группируя слагаемые при $a$ и $b$: $$a \left(y_1 - \left\lfloor \frac{b}{a} \right\rfloor x_1\right) + b x_1 = \gcd(a, b)$$ Откуда получаем рекуррентный переход: $$\begin{cases} x = y_1 - \left\lfloor \frac{b}{a} \right\rfloor x_1 \\ y = x_1 \end{cases}$$

Поиск обратного в $\mathbb{Z}_m$: Рассмотрим уравнение $a x + m y = 1$. Взяв обе части по модулю $m$, получаем $a x \equiv 1 \pmod m \implies x = a^{-1}$. Поиск обратного элемента в $\mathbb{Z}_m$ выполняется за $O(\log m)$ без знания $\varphi(m)$ и факторизации.

// 1. Функция Эйлера за O(sqrt(n))
long phi(long n) {
    long result = n;
    for (long p = 2; p * p <= n; p++) {
        if (n % p == 0) {
            while (n % p == 0) n /= p;
            result -= result / p; // result * (1 - 1/p)
        }
    }
    if (n > 1) {
        result -= result / n;
    }
    return result;
}

// 2. Быстрое бинарное возведение в степень (a^b % mod) за O(log b)
long binPow(long a, long b, long mod) {
    long res = 1;
    a %= mod;
    while (b > 0) {
        if ((b & 1) != 0) res = (res * a) % mod;
        a = (a * a) % mod;
        b >>= 1;
    }
    return res;
}

// 3. Расширенный алгоритм Евклида: возвращает gcd(a, b) и заполняет x, y
long extGcd(long a, long b, long[] xy) {
    if (b == 0) {
        xy[0] = 1; xy[1] = 0;
        return a;
    }
    long[] nextXy = new long[2];
    long g = extGcd(b, a % b, nextXy);
    xy[0] = nextXy[1];
    xy[1] = nextXy[0] - (a / b) * nextXy[1];
    return g;
}

// Обратный по произвольному модулю m
long modInverse(long a, long m) {
    long[] xy = new long[2];
    long g = extGcd(a, m, xy);
    if (g != 1) return -1; // обратного не существует!
    return (xy[0] % m + m) % m;
}
