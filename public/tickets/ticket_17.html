[Определение] Метод потенциалов (The Potential Method)

В отличие от подсчета локальных виртуальных монет, метод потенциалов приписывает всей структуре данных $S$ скалярную величину — потенциал $\Phi(S)$ (меру «напряжения» или накопленной энергии).

Требования к функции потенциала $\Phi(S)$:

  1. $\Phi(S_0) = 0$, где $S_0$ — начальное состояние структуры данных до выполнения операций.
  2. $\Phi(S_i) \ge 0$ в любой момент времени $i \ge 0$. Потенциал никогда не может стать отрицательным.

Учетное (амортизированное) время $i$-й операции:

$$t'_i = t_i + \Delta \Phi_i = t_i + \Phi(S_i) - \Phi(S_{i-1})$$

где $t_i$ — истинное физическое время (число элементарных операций) $i$-го шага, а $\Delta\Phi_i = \Phi(S_i) - \Phi(S_{i-1})$ — изменение потенциала структуры в результате этой операции.

[Теорема] Мажорирование реального времени телескопической суммой

Теорема: Сумма учетных времен мажорирует сумму реальных времен работы для любой последовательности из $n$ операций:

$$\sum_{i=1}^n t_i \le \sum_{i=1}^n t'_i$$

Доказательство: Распишем сумму учетных стоимостей:

$$\sum_{i=1}^n t'_i = \sum_{i=1}^n \left( t_i + \Phi(S_i) - \Phi(S_{i-1}) \right) = \sum_{i=1}^n t_i + \sum_{i=1}^n \left( \Phi(S_i) - \Phi(S_{i-1}) \right)$$

Вторая сумма является телескопической: все промежуточные слагаемые взаимно уничтожаются:

$$\sum_{i=1}^n \left( \Phi(S_i) - \Phi(S_{i-1}) \right) = (\Phi(S_1) - \Phi(S_0)) + (\Phi(S_2) - \Phi(S_1)) + \dots + (\Phi(S_n) - \Phi(S_{n-1})) = \Phi(S_n) - \Phi(S_0)$$

Подставляя граничные условия $\Phi(S_0) = 0$ и $\Phi(S_n) \ge 0$:

$$\sum_{i=1}^n t'_i = \sum_{i=1}^n t_i + \Phi(S_n) - \Phi(S_0) = \sum_{i=1}^n t_i + \Phi(S_n) \ge \sum_{i=1}^n t_i$$

Разделив на число операций $n$, получаем:

$$\frac{1}{n} \sum_{i=1}^n t_i \le \frac{1}{n} \sum_{i=1}^n t'_i$$

Следовательно, среднее учетное время $t'$ сверху ограничивает среднее реальное время выполнения операций.

[Анализ] Применение метода потенциалов к push_back в векторе

Пусть $s$ — текущее число элементов в массиве ($\mathrm{size}$), а $c$ — выделенная вместимость массива ($\mathrm{capacity}$). При заполнении ($s = c$) вместимость удваивается: $c_{\mathrm{new}} = 2c$.

Выбор функции потенциала (Лекция 5, Кулапин):

$$\Phi(S) = 2s - c$$

Проверка условий:

  • Начальное состояние: при пустом массиве $\Phi(S_0) = 0$.
  • Неотрицательность: массив всегда заполнен не менее чем наполовину своей вместимости ($s \ge c/2$). Поэтому $2s \ge c \implies \Phi(S) = 2s - c \ge 0$. Сразу после удвоения $s = c/2 \implies \Phi = 0$ (система разряжена). Непосредственно перед удвоением $s = c \implies \Phi = c > 0$ (система накопила максимальную энергию).

Случай 1: Реаллокация не требуется ($s < c$)

Физическое время: $t_i = 1$ (запись нового элемента). Размер увеличился на 1: $s \to s + 1$, вместимость не изменилась: $c \to c$.

$$\Delta \Phi = (2(s + 1) - c) - (2s - c) = 2$$ $$t'_i = t_i + \Delta \Phi = 1 + 2 = 3$$

Случай 2: Реаллокация требуется ($s = c$)

Физическое время: перекопирование $s$ старых элементов и запись 1 нового элемента: $t_i = s + 1$. Новое состояние: $s' = s + 1$, $c' = 2c = 2s$.

$$\Phi(S_{i-1}) = 2s - s = s$$ $$\Phi(S_i) = 2(s + 1) - 2s = 2$$ $$\Delta \Phi = \Phi(S_i) - \Phi(S_{i-1}) = 2 - s$$

Вычисляем учетное время дорогой операции:

$$t'_i = t_i + \Delta \Phi = (s + 1) + (2 - s) = 3$$
Итог: И при обычной вставке, и при реаллокации учетное время $t'_i \equiv 3 = O(1)$ константно! Накопленный потенциал $\Phi = s$ в точности компенсировал дорогие затраты на копирование.
[Summary] Сводные свойства метода потенциалов
Параметр Обычная вставка ($s < c$) Вставка с удвоением ($s = c$)
Реальное время $t_i$ $1$ $s + 1$
Изменение потенциала $\Delta\Phi$ $+2$ $2 - s$
Учетное время $t'_i = t_i + \Delta\Phi$ $3$ $3$
💻 Реализация DynamicVector с расчетом потенциала $\Phi$ на Java++ 
class PotentialVector {
    private int[] data = new int[1];
    private int size = 0;
    private int capacity = 1;

    // Функция потенциала: Phi = 2 * size - capacity
    int getPotential() {
        return 2 * size - capacity;
    }

    void push_back(int x) {
        if (size == capacity) {
            int newCapacity = capacity * 2;
            int[] newData = new int[newCapacity];
            for (int i = 0; i < size; i++) {
                newData[i] = data[i];
            }
            data = newData;
            capacity = newCapacity;
        }
        data[size] = x;
        size++;
    }

    // Удаление с гистерезисом (сжатие только при size <= capacity / 4)
    int pop_back() {
        int val = data[size - 1];
        size--;
        if (size > 0 && size <= capacity / 4) {
            int newCapacity = capacity / 2;
            int[] newData = new int[newCapacity];
            for (int i = 0; i < size; i++) {
                newData[i] = data[i];
            }
            data = newData;
            capacity = newCapacity;
        }
        return val;
    }
}
