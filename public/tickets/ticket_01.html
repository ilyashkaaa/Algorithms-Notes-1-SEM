[Определение] Ресурсы алгоритма и модель памяти

При анализе алгоритмов рассматриваются два ключевых ресурса:

  1. Время исполнения (временная сложность): Количество элементарных операций, выполняемых алгоритмом для решения задачи на входе размера $n$.
  2. Потребляемая память (пространственная сложность): Объем памяти, требуемый алгоритму для работы при обработке входа размера $n$ (сверх исходных данных).

Модель памяти (из лекции):

  • Память вычислителя предполагается безграничной.
  • Доступ к любой ячейке памяти на чтение или запись требует пренебрежимо малого, константного времени $O(1)$.
♦ Идея асимптотического анализа

Разные вычислители имеют разную производительность, а точное время в секундах зависит от процессора и компилятора. Асимптотический анализ исследует скорость роста функции сложности при неограниченном росте размера входных данных ($n \to \infty$), отбрасывая константные множители и слагаемые младшего порядка.

[Определение] O-нотация (Верхняя оценка)

Пусть имеются две функции $f(n)$ и $g(n)$, при этом $f, g: \mathbb{N} \to \mathbb{N}$ (или $\mathbb{R}^+$). Говорят, что $f(n) = O(g(n))$, если:

$$\exists C > 0, \; \exists N_0 : \forall n > N_0 \implies f(n) \le C \cdot g(n)$$

Смысл: функция $f(n)$ растет не быстрее, чем $g(n)$, начиная с некоторого порога $N_0$, с точностью до постоянного множителя $C$.

[Определение] $\Omega$-нотация (Нижняя оценка)

Пусть имеются две функции $f, g: \mathbb{N} \to \mathbb{N}$. Говорят, что $f(n) = \Omega(g(n))$, если:

$$\exists C > 0, \; \exists N_0 : \forall n > N_0 \implies f(n) \ge C \cdot g(n)$$

Смысл: функция $f(n)$ растет не медленнее, чем $g(n)$, начиная с порога $N_0$. Заметим, что $f(n) = \Omega(g(n)) \iff g(n) = O(f(n))$.

[Определение и Теорема] $\Theta$-нотация (Точный порядок роста)

Пусть имеются две функции $f, g: \mathbb{N} \to \mathbb{N}$. Говорят, что $f(n) = \Theta(g(n))$, если:

$$\exists C_1, C_2 > 0, \; \exists N_0 : \forall n > N_0 \implies C_1 \cdot g(n) \le f(n) \le C_2 \cdot g(n)$$

Критерий эквивалентности:

$$f(n) = \Theta(g(n)) \iff \Big( f(n) = O(g(n)) \quad \text{и} \quad f(n) = \Omega(g(n)) \Big)$$
[Свойства] Алгебра асимптотических оценок
  • Транзитивность: Если $f(n) = O(g(n))$ и $g(n) = O(h(n))$, то $f(n) = O(h(n))$. Аналогично для $\Omega$ и $\Theta$.
  • Рефлексивность: $f(n) = O(f(n))$, $f(n) = \Omega(f(n))$, $f(n) = \Theta(f(n))$.
  • Правило суммы (доминирование): Если $f_1(n) = O(g_1(n))$ и $f_2(n) = O(g_2(n))$, то: $$f_1(n) + f_2(n) = O(\max(g_1(n), g_2(n)))$$ Следствие: При сложении функций порядок роста определяется самым быстрорастущим слагаемым.
  • Правило произведения: Если $f_1(n) = O(g_1(n))$ и $f_2(n) = O(g_2(n))$, то $f_1(n) \cdot f_2(n) = O(g_1(n) \cdot g_2(n))$.
  • Константы: Для любого $k > 0$ имеем $O(k \cdot g(n)) = O(g(n))$.
[Примеры] Примеры из лекции с подбором констант

Пример 1 (из лекции 1, слайд 5): Доказать, что $f(n) = n = O(n^2)$.

Пусть $f(n) = n$, а $g(n) = n^2$. Выберем константы $C = 1$ и $N_0 = 2$. Тогда для всех $n > N_0$ (то есть $n \ge 2$): $$f(n) = n \le 1 \cdot n^2 = C \cdot g(n)$$ Неравенство $n \le n^2$ верно для всех $n \ge 2$, следовательно, по определению $n = O(n^2)$.

Пример 2 (из лекции 1, слайд 5): Многочлены степеней $k$ и $k + \alpha$.

Пусть $f(n) = P_k(n)$, а $g(n) = P_{k+\alpha}(n)$, где $P_r(n)$ — произвольный многочлен степени $r$, при этом $k \in \mathbb{N}, \alpha \in \mathbb{N}_0$. Так как при $n \to \infty$ поведение многочлена определяется старшей степенью $n^{k+\alpha} \ge n^k$, существует $C > 0$ и $N_0$, такие что для всех $n > N_0$: $$P_k(n) \le C \cdot P_{k+\alpha}(n) \implies P_k(n) = O(P_{k+\alpha}(n))$$

Пример 3 (Подбор констант для $\Theta$): Доказать, что $3n^2 + 5n = \Theta(n^2)$.

При $n \ge 1$: $$3n^2 \le 3n^2 + 5n \le 3n^2 + 5n^2 = 8n^2$$ Положив $C_1 = 3, C_2 = 8, N_0 = 1$, получаем $C_1 n^2 \le 3n^2 + 5n \le C_2 n^2$, откуда $3n^2 + 5n = \Theta(n^2)$.

💻 Примеры анализа сложности фрагментов кода на Java++ 
// 1. O(1) - константное время: доступ по индексу и элементарные операции
int getMiddle(int[] arr, int n) {
    return arr[n / 2]; // 1 операция обращения к памяти
}

// 2. O(log n) - логарифмическое время: деление размера задачи пополам
int countHalves(int n) {
    int steps = 0;
    while (n > 1) {
        n /= 2;
        steps++;
    }
    return steps;
}

// 3. O(n^2) - квадратичное время: два вложенных цикла
long sumPairs(int[] arr, int n) {
    long sum = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            sum += arr[i] * (long)arr[j]; // n*(n-1)/2 итераций = Theta(n^2)
        }
    }
    return sum;
}
