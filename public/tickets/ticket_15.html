[Определение] Базовая сортировка подсчетом (Counting Sort)

Пусть элементы массива $A[0 \dots n-1]$ принадлежат небольшому целочисленному универсуму $[0, K-1]$.

Базовый алгоритм:

  1. Выделяем массив счетчиков $cnt$ длины $K$, инициализированный нулями.
  2. Проходим по массиву $A$ и подсчитываем частоту каждого ключа: $cnt[A[i]]++$.
  3. Последовательно выводим каждый ключ $x \in [0, K-1]$ ровно $cnt[x]$ раз обратно в массив $A$.

Сложность: Время $O(n + K)$, память $O(K)$.

Главный недостаток базового варианта: Он нестабилен и применим только если сортируются «голые» числа без ассоциированных данных. Если элементы являются структурами с ключом и значением (satellite data), базовая сортировка просто уничтожит исходные объекты.
[Алгоритм] Стабильная сортировка подсчетом (Stable Counting Sort)

Стабильность: Элементы с равными ключами обязаны сохранить взаимный порядок следования, который был у них в исходном массиве.

Лекционный алгоритм с префиксными суммами:

  1. Заводим массив частот $P[0 \dots K-1]$ и выходной буфер $B[0 \dots n-1]$.
  2. Подсчитываем количество элементов каждого ключа: для каждого $x \in A$ делаем $P[x.\mathrm{key}]++$.
  3. Префиксные суммы: Заменяем значения в $P$ их префиксными суммами: $$P[i] = P[i] + P[i - 1] \quad (\text{для } i \text{ от } 1 \text{ до } K - 1)$$ Теперь $P[i]$ указывает общее число элементов с ключом $\le i$, то есть правую границу сегмента для ключа $i$ в выходном массиве $B$.
  4. Проход справа налево (гарантия стабильности): Итерируемся по массиву $A$ в обратном порядке от $n-1$ до $0$:
    • Берем элемент $x = A[i]$ с ключом $k = x.\mathrm{key}$.
    • Помещаем его на позицию $P[k] - 1$ в массиве $B$: $B[P[k] - 1] = x$.
    • Уменьшаем счетчик: $P[k]--$.
Почему справа налево? Элемент, стоящий правее всех среди дубликатов с ключом $k$, получит самый большой доступный индекс в группе ключа $k$, сохранив исходный порядок следования!
[Алгоритм] Поразрядная сортировка LSD (Least Significant Digit)

LSD Radix Sort позволяет сортировать целые беззнаковые числа (или строки одинаковой длины), выходящие за пределы малого диапазона, за строго линейное время $O(n)$.

Идея алгоритма:

  • Представим каждое число в системе счисления с основанием $R$ (radix). Например, для 32-битных чисел удобно взять основание байта $R = 256 = 2^8$, тогда каждое число разбивается ровно на $d = 4$ разряда (байта).
  • Сортируем числа последовательно по разрядам, двигаясь от младшего разряда к старшему (от 0-го байта к 3-му).
  • На каждой из $d$ фаз сортировка по текущему разряду производится с помощью стабильной сортировки подсчетом (Stable Counting Sort) с размером алфавита $K = R$.
[Теорема и Доказательство] Корректность LSD Radix Sort

Теорема: После $d$ фаз стабильной сортировки подсчетом по разрядам от младшего к старшему массив будет полностью упорядочен.

Доказательство по математической индукции:

  • База индукции ($i = 1$): После сортировки по 0-му (младшему) разряду все элементы упорядочены по своему младшему разряду.
  • Индукционный переход ($i - 1 \to i$): Предположим, что после $(i-1)$ шагов элементы массива упорядочены по своим младшим $i-1$ разрядам.

    Рассмотрим шаг $i$, где происходит стабильная сортировка по $i$-му разряду. Пусть сравниваются два произвольных числа $x$ и $y$:

    • Случай 1: У чисел разные $i$-е разряды. Тогда сортировка подсчетом на шаге $i$ расставит их в соответствии со значением $i$-го разряда. Так как более старший разряд важнее всех младших, порядок чисел корректен.
    • Случай 2: У чисел одинаковые $i$-е разряды. В силу стабильности фазы сортировки их относительный порядок не изменится. А по предположению индукции их взаимный порядок уже был правильным по младшим $(i-1)$ разрядам!

Следовательно, после $d$ шагов числа будут полностью упорядочены по всем разрядам.

[Summary] Сводные параметры Counting Sort и LSD
Алгоритм Время работы Память Стабильность Ключевое применение
Базовый Counting $O(n + K)$ $O(K)$ Нет Массив скаляров в малом диапазоне
Стабильный Counting $O(n + K)$ $O(n + K)$ Да Сортировка объектов со спутниковыми данными

💻 Реализация 4-байтового LSD Radix Sort на Java++ 
class RadixSortLSD {
    // Побайтовая сортировка LSD 32-битных беззнаковых чисел за 4 прохода
    void radixSort(int[] a) {
        int n = a.length;
        int[] buffer = new int[n];
        int R = 256; // Основание: 1 байт = 8 бит (256 возможных значений)

        for (int byteIdx = 0; byteIdx < 4; byteIdx++) {
            int shift = byteIdx * 8;
            int[] count = new int[R];

            // 1. Подсчет частоты байта
            for (int i = 0; i < n; i++) {
                int b = (a[i] >>> shift) & 0xFF;
                count[b]++;
            }

            // 2. Префиксные суммы (правые границы сегментов)
            for (int i = 1; i < R; i++) {
                count[i] += count[i - 1];
            }

            // 3. Стабильное распределение: проход справа налево!
            for (int i = n - 1; i >= 0; i--) {
                int b = (a[i] >>> shift) & 0xFF;
                buffer[count[b] - 1] = a[i];
                count[b]--;
            }

            // Копируем отсортированные данные обратно в массив a
            System.arraycopy(buffer, 0, a, 0, n);
        }
    }
}
