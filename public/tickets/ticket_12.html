Алгоритм медианы медиан

[Определение] Задача поиска детерминированного пивота

В алгоритме Quick Select случайный выбор опорного элемента дает среднее время $O(n)$, но оставляет риск худшего случая $O(n^2)$.

Алгоритм медианы медиан: Находит такой опорный элемент, который гарантированно делит массив в фиксированной пропорции, устраняя худший случай $O(n^2)$ и обеспечивая детерминированное линейное время $O(n)$ в наихудшем случае.

[Алгоритм] Поиск медианы медиан

Алгоритм поиска опорного элемента $M$ для массива $A$ размера $n$:

  1. Разбиение на группы: Массив разбивается на $\lceil n/5 \rceil$ групп по 5 элементов (последняя группа может содержать от 1 до 5 элементов).
  2. Поиск локальных медиан: В каждой пятерке за константное число сравнений $O(1)$ находится медиана (3-й по величине элемент).
  3. Сбор медиан: Найденные $\lceil n/5 \rceil$ медиан собираются в отдельный массив $B$.
  4. Рекурсивный вызов: Рекурсивно вызывается алгоритм поиска порядковой статистики для нахождения медианы массива $B$ — элемента $M = \mathrm{Select}\left(B, \lfloor |B|/2 \rfloor\right)$. Элемент $M$ называется медианой медиан.
[Теорема и Доказательство] Гарантия сбалансированности $7n/10$

Теорема: Опорный элемент $M$ (медиана медиан) отсекает как минимум $3n/10$ элементов с каждого конца массива. Следовательно, после $\mathrm{Partition}(M)$ ни одна из двух частей не может содержать более $7n/10$ элементов.

Доказательство:

  • Всего имеется $m = \lceil n/5 \rceil$ пятерок.
  • Элемент $M$ является медианой массива медиан, следовательно, как минимум половина медиан пятерок не меньше $M$: $$\text{Число пятерок с медианой } \ge M \quad \ge \quad \frac{1}{2} \left\lceil \frac{n}{5} \right\rceil \ge \frac{n}{10}$$
  • В каждой такой пятерке сама медиана и два элемента, которые не меньше нее, гарантированно $\ge M$ (всего $3$ элемента на группу).
  • Исключая неполную группу и группу самого $M$, получаем число элементов, гарантированно больших либо равных $M$: $$\text{Количество элементов } \ge M \quad \ge \quad 3 \cdot \left( \frac{1}{2} \cdot \frac{n}{5} - 2 \right) \ge \frac{3n}{10} - 6$$
  • Симметрично, как минимум половина медиан пятерок $\le M$, и в каждой такой пятерке не менее 3 элементов $\le M$. Следовательно: $$\text{Количество элементов } \le M \quad \ge \quad \frac{3n}{10} - 6$$
Вывод: При разбиении массива элементом $M$ размер большей подзадачи для следующего шага не превосходит: $$n - \frac{3n}{10} = \frac{7n}{10} \quad (\text{для достаточно больших } n)$$
[Теорема] Линейная сложность медианы медиан в худшем случае

Рекуррентное соотношение для времени работы $T(n)$:

  • Разбиение на пятерки и поиск медиан в них: $O(n) \le c_1 n$.
  • Поиск медианы медиан в массиве размера $n/5$: $T(n/5)$.
  • Разбиение $\mathrm{Partition}$ массива размера $n$ по элементу $M$: $c_2 n$.
  • Рекурсивный спуск в одну из половин размером не более $7n/10$: $T(7n/10)$.
$$T(n) \le T\left(\frac{n}{5}\right) + T\left(\frac{7n}{10}\right) + cn$$

Доказательство по индукции (Лекционный метод Кулапина): Докажем, что $T(n) \le 10 c n$.

База индукции: Для малых $n < n_0$ алгоритм сортирует массив тривиально за $O(1)$, подбором константы неравенство $T(n) \le 10 c n$ выполняется.

Индукционный переход: Предположим, что для всех $k < n$ утверждение верно: $T(k) \le 10 c k$. Тогда:

$$\begin{aligned} T(n) &\le T\left(\frac{n}{5}\right) + T\left(\frac{7n}{10}\right) + cn \\ &\le 10 c \left(\frac{n}{5}\right) + 10 c \left(\frac{7n}{10}\right) + cn \\ &= 2 c n + 7 c n + cn \\ &= 10 c n \end{aligned}$$

Индукционный переход полностью доказан! Следовательно, $T(n) = O(n)$ в худшем случае.

[Анализ] Почему именно 5 элементов в группе?

Ключевое условие сходимости к $O(n)$ — сумма коэффициентов аргументов рекурсии должна быть строго меньше 1:

$$\alpha = \frac{1}{k} + \left(1 - \frac{\lceil k/2 \rceil}{2k}\right) < 1$$
  • Если группы по 3: медиана медиан гарантирует $2 \cdot \frac{n}{6} = \frac{n}{3}$ элементов. Рекуррентность: $$T(n) \le T\left(\frac{n}{3}\right) + T\left(\frac{2n}{3}\right) + cn$$ Сумма долей: $\frac{1}{3} + \frac{2}{3} = 1$. Дерево рекурсии имеет глубину $\Theta(\log n)$ с работой $cn$ на каждом уровне, что дает $T(n) = \Theta(n \log n)$ — линейность исчезает!
  • Если группы по 5: сумма долей: $$\frac{1}{5} + \frac{7}{10} = \frac{2}{10} + \frac{7}{10} = \frac{9}{10} < 1$$ Строго меньше 1 — ряд сходится, давая $O(n)$. 5 — наименьшее нечетное число, дающее сумму $< 1$.
  • Если группы по 7: сумма долей $\frac{1}{7} + \frac{5}{14} = \frac{1}{2} < 1$, но константа на сортировку 7 элементов заметно выше.
[Summary] Сводные тезисы билета
  • Цель алгоритма: Детерминированный поиск опорного элемента, отсекающего не менее $30\%$ элементов с каждого конца.
  • Размер группы: Ровно 5 элементов. При 3 элементах сумма долей равна 1 и алгоритм деградирует в $O(n \log n)$.
  • Рекуррентность: $T(n) \le T(n/5) + T(7n/10) + cn$.
  • Оценка времени: Худший случай $O(n)$ с индуктивной константой $10c$.
💻 Реализация алгоритма медианы медиан на Java++ 
class MedianOfMedians {
    // Сортировка малых отрезков вставками (до 5 элементов)
    void insertionSort(int[] a, int l, int r) {
        for (int i = l + 1; i <= r; i++) {
            int cur = a[i], j = i - 1;
            while (j >= l && a[j] > cur) {
                a[j + 1] = a[j];
                j--;
            }
            a[j + 1] = cur;
        }
    }

    // Поиск медианы медиан (пивота) на отрезке [l, r]
    int getPivot(int[] a, int l, int r) {
        int n = r - l + 1;
        if (n <= 5) {
            insertionSort(a, l, r);
            return a[l + n / 2];
        }

        // 1. Делим на пятерки и собираем медианы в префикс массива
        int numMedians = 0;
        for (int i = l; i <= r; i += 5) {
            int subR = Math.min(i + 4, r);
            insertionSort(a, i, subR);
            int medianIdx = i + (subR - i) / 2;
            swap(a, l + numMedians, medianIdx);
            numMedians++;
        }

        // 2. Рекурсивно находим медиану собранных медиан (T(n/5))
        return select(a, l, l + numMedians - 1, l + numMedians / 2);
    }

    // Детерминированный Select за O(n) худшего времени
    int select(int[] a, int l, int r, int k) {
        if (l == r) return a[l];

        int pivot = getPivot(a, l, r);

        // Partition вокруг найденного pivot
        int m = partitionValue(a, l, r, pivot);

        if (m == k) return a[m];
        if (k < m)  return select(a, l, m - 1, k);
        return select(a, m + 1, r, k);
    }

    int partitionValue(int[] a, int l, int r, int pivot) {
        for (int i = l; i <= r; i++) {
            if (a[i] == pivot) { swap(a, i, r); break; }
        }
        int m = l;
        for (int i = l; i < r; i++) {
            if (a[i] < pivot) { swap(a, m, i); m++; }
        }
        swap(a, m, r);
        return m;
    }

    void swap(int[] a, int i, int j) {
        int tmp = a[i]; a[i] = a[j]; a[j] = tmp;
    }
}
