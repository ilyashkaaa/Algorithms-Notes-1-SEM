## 📋 Структура конспекта билета

Каждый билет оформлен по строгой академической структуре, необходимой для успешного ответа на коллоквиуме:

1. **Определение** — математически выверенные и строгие формулировки.
2. **Геометрическая или физическая интерпретация** — наглядное понимание сути структуры или алгоритма.
3. **Теоремы и леммы** — четкие формулировки условий и утверждений.
4. **Строгие доказательства** — доказательства корректности, высоты и временной сложности без пропусков логики.
5. **Алгоритмы и псевдокод** — базовые и вспомогательные операции с разбором инвариантов.
6. **Блиц-паспорт билета (Summary)** — ключевые тезисы для повторения за 2 минуты до входа в аудиторию.
7. **Подводные камни и вопросы экзаменаторов** — частые ошибки и каверзные вопросы на защите билета.

## 🗺️ Программа билетов коллоквиума

<details>
<summary><b>Модуль 1: Анализ алгоритмов, Поиск и Теория чисел (Билеты 01–09)</b></summary>

- `01` Сложность алгоритма, модели вычислений RAM, $O, \Theta, \Omega$.
- `02` Бинарный поиск: алгоритм, корректность, поиск вещественного числа.
- `03` Префиксные суммы и обобщения на случай полугрупп.
- `04` Тернарный поиск: поиск экстремума унимодальной функции.
- `05` Решето Эратосфена: $O(n \log \log n)$ и линейное $O(n)$.
- `06` Быстрое возведение в степень, Диофантовы уравнения, расширенный алгоритм Евклида.
- `07` Модулярная арифметика: МТФ, теорема Эйлера, алгоритм поиска обратного элемента.
- `08` Метод двух указателей и метод сканирующей прямой.
- `09` Битовые операции: битовые маски, встроенные функции, оптимизация операций с множествами.

</details>

<details>
<summary><b>Модуль 2: Сортировки и Базовые структуры данных (Билеты 10–20)</b></summary>

- `10` Квадратичные сортировки: Bubble sort, Insertion sort, Selection sort.
- `11` Сортировка слиянием (Merge Sort): рекурсивный и итеративный алгоритмы, анализ инверсий.
- `12` Быстрая сортировка (Quick Sort): разделение Хоара и Ломуто, рандомизация, худший и средний случай.
- `13` Теорема о нижней границе сортировок сравнениями: дерево решений.
- `14` Несравнивающие сортировки: Counting sort, Radix sort, Bucket sort.
- `15` Порядковые статистики: Quick Select (среднее $O(n)$) и Introselect ($O(n)$ худший).
- `16` Стек, Очередь, Дек: реализация на массиве и связном списке, амортизированный анализ.
- `17` Стек с поддержкой минимума за $O(1)$, Очередь с поддержкой минимума за $O(1)$.
- `18` Куча (Heap): свойства двоичной кучи, просеивания `siftUp`, `siftDown`.
- `19` Построение кучи за $O(n)$ (`buildHeap`), пирамидальная сортировка (Heap Sort).
- `20` Система непересекающихся множеств (DSU): эвристики ранга/веса и сжатия путей, амортизация.

</details>

<details open>
<summary><b>Модуль 3: Деревья поиска и Запросы на отрезках (Билеты 21–29)</b></summary>

- `21` Двоичное дерево поиска (BST): поиск, вставка, удаление, обходы.
- `22` **Декартово дерево (Treap)**: операции `Split`, `Merge`, выразимость остальных операций, теорема о высоте ✅ *(Готов)*
- `23` АВЛ-дерево (AVL-Tree): инвариант сбалансированности, малые и большие вращения.
- `24` Дерево Фенвика (Binary Indexed Tree): префиксные суммы и точечные обновления за $O(\log n)$.
- `25` Постановка задач RMQ и RSQ: статика против динамики, online против offline.
- `26` Разреженная таблица (Sparse Table): построение за $O(n \log n)$, RMQ за $O(1)$.
- `27` Дерево отрезков (Segment Tree): построение за $O(n)$, точечные запросы за $O(\log n)$.
- `28` Дерево отрезков с групповым обновлением: техника ленивого проталкивания (Lazy Propagation).
- `29` Treap по неявному ключу: применение для работы с массивом, разворот подотрезка за $O(\log n)$.

</details>

## 💻 Локальный запуск

Если вы хотите запустить проект локально на своем компьютере:

```bash
# Клонируйте репозиторий
git clone https://github.com/ilyashkaaa/algo_collloc.git
cd algo_collloc

# Запустите локальный веб-сервер на Python
python3 -m http.server 8000 --directory public
```

После этого перейдите в браузере по адресу: **[http://localhost:8000](http://localhost:8000)**.

Также можно просто открыть файл `public/index.html` двойным кликом в браузере.
